# 需求、身份与交付适配

适用：接入Brief、识别范围和用途、陌生活动或条件改变。先读推导和四态；按实际作者、读者及动作读取矩阵。类型表是定位与补漏，不能据一个名字复制套餐。

## 从第一性原理生成需要

活动是在当前委托与条件下，为特定对象组织真实内容，使其获得可辨识价值。价值可以是欣赏、理解、学习、表达、关系、服务或交易。先回答六类输入，再展开任务：

| 输入 | 需要确定的内容 | 对研究与生产的影响 |
|---|---|---|
| 意图与委托 | 为什么做、代表谁、负责什么、如何判断值 | 目标、范围、取舍、成立理由 |
| 服务对象 | 处境、已有认知/能力、动机与阻力，参与者与受益者是否分离 | 具体所得、表达、准入和服务 |
| 内容原料 | 产品、作品、知识、人物、地方、组织事实和可用服务 | 原始资料、独特依据、能写什么 |
| 发生方式 | 看、听、交流、演示、操作、创作、仪式、交易或服务动作 | 内容结构、规则、节奏与完成点 |
| 条件关系 | 时间、空间、技术、人员、容量、费用、合作与权限 | 机会、依赖、必要补查和限制 |
| 接手用途 | 谁决定、制作、采购、发布、服务、执行或复盘 | 正文深度、载体、附件与验收 |

可在一份Brief中表达，不要求六张表。重要要求可追到“来源 → 为什么需要 → 内容/工作 → 成立条件 → 缺口 → 补查 → 处理 → 影响”；普通句子无需逐条备案。未知动机保留未知，不能凭国企、员工、高端、艺术、客户等标签推导政绩、留人、财富偏好或出圈目标。

适配还核目标与对象关系、场域、时间组织、开放方式、主体关系、作者委托、文档用途、成熟度和复杂度。认知/情感/行为/关系/资源/身份/能力，参与者/受益者，接受/参与/仪式/连接/共创，线上/线下/混合与单次/周期，是补漏角度，不保证穷尽或互斥。无法归类时从真实动作生成新任务，不改写用户需求以便套型。

## 适用性与任务契约

| 状态 | 当前处理 | 不能混写 |
|---|---|---|
| 现在需要 | 确定实际正文/工作件、输入、接收和完成标准 | 有目录不等于有正文 |
| 后续需要 | 留触发条件、依赖、预期时间/接收和当前边界 | 不提前宣称后续已交 |
| 本次不需要 | 对有争议项说明范围或动作不存在，不建空模块 | 不需要不等于内容未完成 |
| 尚不能判断 | 留具体缺口、影响、补查与判断节点 | 未知不得静默跳过 |

每项实质任务说明需求依据、本次问题、适用状态、来源输入、作者和接收者、实际产物、深度、依赖、验收、未决及影响。项目实际需要却未包含在当前委托的工作要显示影响，明确谁承接或调整承诺；增强项仍是可选，不暗增工作、费用和对外承诺。

## 八类作者：输入、权利与交付

现实作者身份与AI专业视角分开。服务范围来自委托和有效授权，不来自角色名称。

| 作者 | 必须取得的输入 | 现实权利和确认边界 | 本次交付重点 |
|---|---|---|---|
| 甲方市场/品牌/运营 | 目标、产品/品牌事实、预算、内部资源/责任、历史资料 | 决策和自有资源权限须实际确认；不能代表所有部门 | 人群价值、内容、投入取舍、资源分配、主判据与接口 |
| HR/行政/内部沟通 | 人数、组织信息、真实贡献/表彰规则、员工条件、内部资料范围 | 内部审核、参与安排和公开权限分别确定 | 员工所得、组织表达、节目/任务、服务与跨部门安排 |
| 乙方策略/创意 | 正式Brief、用途、阶段、预算、采购/竞标条件、客户提供资料 | 可交创作与甲方/第三方资源承诺分开；拟案不当预订 | 实际策略/概念/文案、匹配与取舍、服务深度及交付边界 |
| 执行承包/制片 | 已定及待核内容、场地/技术、供应、合同、规格与时窗 | 不擅改主方向，不代主办承担未受托义务 | 排产、ROS/技术调度、岗位、采购接口、验收与异常 |
| 媒介/达人/内容服务 | 事实证据、账号/平台能力、素材权利、预算、稿件数量与接收端 | 内容制作、发布、投放与交易/售后权分别约定 | 实际稿件/Brief、生产日历、入口、回应和可得数据 |
| 主办/联合主办 | 内容、公众与伙伴关系、真实资源、各方责任及决定接口 | 最终责任接口要明确；联合名义不代表所有人已批准 | 整体内容及履约、参与服务、协作、条件和生命周期 |
| 赞助/品牌合作方 | 真实权益库存、排他、授权、价格、受众与履约证明 | 不能出售未持有资源，不能保证未知曝光、名单或结果 | 权益价值、内容位置、限制、投入、交出/接收及证明 |
| 独立顾问/局部作者 | 指定任务、现有资料、用途与接收者、修改范围 | 建议或文本不能称已锁定执行；资料访问按必要范围 | 约定研究、判断或实际文字工作件及边界、下一接口 |

身份变化更新相应立场、范围、权利和接收，不静默重写既有事实。兼多职能时仍定位对应费用和责任。

## 十一类读者：按接手动作提供材料

| 接收职能 | 要完成的动作 | 需取得的输入/证据 | 交出方式与验收 |
|---|---|---|---|
| 老板/预算决策者 | 判断做不做、投入与取舍 | 推荐、实际内容价值、费用、备选损失、关键未决 | 短决策层连到关键正文；能作当前决定 |
| 品牌/市场负责人 | 判断方向与内容是否成立 | 完整活动介绍、原料、主张、体验、范围与状态 | 可连读正文及必要参考，能评审内容及承诺 |
| 采购/财务 | 核成本、付款、范围和验收 | 报价、主账依据、含税/币种/包含边界、里程碑、变更取消 | 可对账的实际项目与付款验收条件 |
| 执行/制片/供应方 | 排产、调度并履约 | 内容/脚本版本、时序、岗位、规格、资源、技术、异常 | 操作件、cue和交接；不用重新创作规则 |
| 内容/设计/影像制作 | 写、画、拍、剪或生产 | 实际文本、对象/动作/场景、必要上下文、规格、源件、权利 | 当前深度的Brief/成稿、反馈与可用文件 |
| 社媒/媒介/达人 | 制作、核稿、发布和回应 | 真实事实、实际稿/任务、节点、授权、账号、入口、当前服务 | 稿件与发布任务分开，能从稿件走到真实接收 |
| 销售/客服/客户成功 | 接收、答疑、跟进和兑现 | 规则/话术、资格字段、归属、响应窗口、升级、追踪 | 可用接收流程及完整回答，不只一列“跟进” |
| 嘉宾/主持/艺术家/导师 | 提供内容或按内容协作 | 议题与证据、具体任务、时段、提示/串词、技术、权利 | 角色Brief及当前稿件，未确认观点不代其发言 |
| 合作/赞助/商户 | 交资源并收约定权益 | 交出/接收、库存/排他、素材、节点、费用、限制、证明 | 双方能确认履约对象和不足处理 |
| 参与者/观众 | 判断参加及如何完成 | 具体价值、适合谁、时间地点/入口、步骤、费用、条件、变更 | 实际可读服务文本及退出/异常路径 |
| 专业/当地相关责任方 | 核相应真实条件并接手 | 动作性质、参数、主体、地点时间、所需附件及原始证据 | 本次核查对象清楚，不以营销叙事代参数 |

接口写明“我方交出者—实际接收职能/人—内容与版本—截止—通过标准—退回及异常路径”。姓名或联系方式未落实就写待指派。读者可以共用事实和正文的不同阅读层；不同操作用途按需要分件，不默认十一套文件。

## 类型契约与场景补漏

只命中真实动作和本次责任的项目展开。下表指明应查的实质问题及正文，不规定文件数量：

| 类型/责任 | 研究对象和正文核心 | 不自动承担 |
|---|---|---|
| 线上获客/付费营销 | 需求、产品证据、稿件、页面、账号、线索接收与测量 | 无现场不做场地ROS |
| 社交传播/UGC | 表达动机、任务规则、实际稿件、投稿回应、授权与展示 | 预写自然好评或全平台铺发 |
| 直播电商 | 真实品项/价格库存、演示脚本、技术调度、付款售后 | 内容方代商家确认库存与退款 |
| 线上论坛/培训/发布 | 议题/课程、主持嘉宾、接入互动、演示、回放和故障 | 虚构线下观众动线 |
| 门店试用/品牌体验 | 真正试什么、产品条件、讲解/操作、排队服务与退出 | 没销售目标强留资/购买 |
| 快闪/市集/开放空间 | 真实品项/单元、摊商、空间服务、开放规则与承载 | 人次当去重人数，全部娱乐化 |
| 产品发布 | 发布事实、使用问题、证据/演示、Q&A与公开口径 | 未确认参数/媒体/阵容 |
| To B交流/合作路演 | 买方/伙伴问题、议题证据、合作条件、邀请与后续 | 未有销售任务强造SQL/签约 |
| 展会主办 | 展商观众双边价值、招展、展位/服务库存、场馆接口 | 只有漂亮展位而无履约 |
| 展会参展 | 自身目标账户、展品、演示、展位人员/物流与接收 | 主办全展票务及全馆运行 |
| 峰会/圆桌/闭门会 | 每段具体问题、证据、追问、分歧、收口与内容保密 | 嘉宾名录当内容，预编共识 |
| 文化节/展览/演出 | 作品/文化原料、策展/叙事、具体单元、观看所得与权利 | 套某城市/社区气质、强剧情/交易 |
| 内部年会/表彰 | 组织事实、贡献、员工所得、节目/任务及内部服务 | 强制表演或自动公开员工资料 |
| 政企仪式/接待 | 真实事项、主体权限、讲解/仪式、礼宾和适用口径 | 模拟批准、虚构领导/政策 |
| 公益/社区服务 | 受益需求、实际服务、人员/款物流、接收和披露 | 传播量当受益成效 |
| 赛事/评奖/共创 | 真实任务、规则版本、资格、判定申诉、成绩/作品和奖项 | 泛UGC规则代专业赛制 |
| 工作坊/学习 | 先备能力、输入、示范练习、反馈和真实完成物 | 交空表当学会，增加无关营销 |
| 招聘/雇主品牌 | 岗位/人数与条件、真实员工案例、问答、投递和反馈 | 虚构岗位承诺、只给价值观口号 |

陌生任务继续沿六类输入和接口生成，必要专业动作见[条件推演](condition-reasoning.md)，具体履约见[执行与复杂度](execution-and-complexity.md)。
