# 一场活动怎样和策划人一起完成

新委托从第一步开始，已有方案从当前问题进入。每轮打开用户上次看到的正文和最新意见，继续写到眼前的决定足够清楚，再把选择交还给有权的人。书中提出的专业问题及阅读范围见[行业书籍](event-planning-books.md)。三次人工决定是本项目的协作设计。

## 七项工作及实际产出

| 环节与输入 | 助手要做的工作 | 策划人收到的实际文字 | 人的决定与下一步 |
|---|---|---|---|
| 1 读懂委托。读原话、已有稿、本轮用途 | 按[分流规则](event-routing.md)识别今天要作的决定、决定者、截止和受影响的人。两种目标争同一资源时，把两种用途都写清楚 | **简报判断。** 保住主创看重的想法，说明此刻交什么、哪些取舍已定、哪个条件会改变结论 | **A 确认委托。** 委托人可确认、补充、改优先级或暂缓。已有原话明确覆盖目标和本轮范围时直接采用 |
| 2 为当前选择做研究。读简报、项目原料与相关原件 | 先锁定一个答案会改变设计的问题。找能支持和削弱设想的原始材料，指出已经看到的细节。产品演示查能否观察到差异，工作坊查操作难点与反馈条件 | **研究判断。** 把“哪份材料的哪个细节、它改变哪项判断、因此哪段要改、缺什么会翻案”写成自然段。需要选材料时附候选、价格或权限状态和原出处 | 资料足以试写即做原型。拿不到关键材料就缩小结论，给核法或带条件的做法。用户无需替助手抄材料或填完整问卷 |
| 3 把当前分歧写到可以选择。输入为主创原意、研究原件及本轮要解决的问题 | 把主创的想法推到最有说服力。若比较现场体验，让同一人分别走两种做法；若要判断投资、主张、接收或合作，按[决定分流](event-routing.md)取对应的实物和可比依据 | **方向选择稿。** 直接给能改变这位读者判断的材料、推荐、代价及翻案条件。已有决定作为后续工作的前提保存 | **B 选择方向。** 只确认负责人实际选定的事项。单纯选中创意，继续共写和研究。委托已明确约定开写范围及触发条件时沿用 |
| 4 在受托范围内逐章接笔。读主创原段、受众、读者与约定深度 | 各章先回答该读者的问题，再连接上下章。体验章从第一次接触写到结束；投资章说明替代用途与追加所得；业务承接章写清资格、交接及无法履约时怎么办 | **连续方案正文或受托章节。** 论坛给具体议题与追问，工作坊给练习和完成物。需要较早交领导的判断可先成独立阅读稿 | 在已授权的深度内迭代。新证据推翻某个经营理由时，将该项交还给有权者；可独立成立的主创内容继续沿用 |
| 5 检验能否兑现。读节目、时间、空间、人员、报价或平台材料 | 挑最紧的一处走一遍，如完成一轮试用后需多久复位、工作人员是否同时负责另一处。核关键资源、容量、工时、费用及失效时的替代。凡会否决方向的条件提前到 B 前检查 | **投入说明和执行附件。** 决策人看到钱和人花在哪里、减掉一项会失去什么；接手者看到时点、动作、物料、交接与异常。未知数值写明待核的量 | 普通计算由助手完成。新增授权、预算取舍或承诺变化请实际负责人决定。概念稿可以带条件；执行交接须满足该用途的实际前提 |
| 6 编辑并交读者审阅。输入为完整内容、历次意见与指定用途 | 先脱离后台材料独立通读正文，再从接收者角度做一次辨别任务。决策人能否说清项目及待定投入？执行者能否按说明启动一个环节，遇到意外能找到下一步？改写卡住的位置 | **指定版本的客户审阅稿或工作件。** 客户先读参加理由、现场过程、关键投入与条件。执行者拿到可操作的文件。按[成稿示例](reader-delivery.md)点收约定内容、格式及附件 | **C 审阅交付。** 由接收者指明采纳的版本和范围，或指出退改处。未回复就保持待审；哪段改了，让人能在新版找到。内部走读只记录为内部检查 |
| 7 用实绩复盘。需要受托且取得真实观察或记录 | 对照最初目标核实际参与、退出、投入、服务兑现和异常。检查记录遗漏、其它解释和由谁承担额外成本 | **复盘意见。** 写清发生了什么、依据何在、哪个设计该保留或改动。活动前只能交观察办法，说明谁在何时记录什么 | 有真实证据再提出下次改法。效果与归因判断标明置信度 |

## 得到答复以后怎样改

- **具体选择。** “选小组练习，保留原来那段演示”意味着把原演示改作练习前的示范。下一轮交示范怎样过渡到练习的实质段落，保留用户选中的部分。
- **有条件的试写。** “先写五分钟开场看看”只授权拿一段内容比较；“预算批了再定”保留为条件。可继续查各方案共用的事实，等待期间不推进依赖未决选择的正式生产。
- **退改或意见改变。** 保住用户点名的那一处，指出哪一个动作、表达或承诺需要改变，直接给改后的正文。若从“让人看懂”改成“让人学会”，补上练习、反馈和观察口径，查证仍有效的背景继续沿用。
- **接续与验收。** 先用一句话交代上次选了什么和本轮正在改什么。记录真实回复的出处、决定者、日期、适用范围与版本；出现相矛盾的新回复，核其是否替代前一决定。正式项目中的决定与版本按[运行协议](runtime-protocol.md)保存。

## 两阶段及小任务接入

全案的第一次交接须能让新写作者打开主创原稿、辨认可编辑的范围、找出被保留和被放弃的方向，并知道每一章该承担的内容。按[主创底稿与逐章写作](author-and-chapter-writing.md)把已完成的研究、试写及真实取舍接到实际章节。研究若涉及会变化的条件、参与者中途选择或岗位共用资源，采用[动态研究与推演](dynamic-research-and-simulation.md)。重要发现先落回主创正在讨论的那一段，之后随方针传给写作者。

第一阶段解决为什么做、为谁、有什么可用原料、选择哪种内容与方式、依哪些条件成立。实际产物包括需求契约、研究判断、内容原型、采用与未采用理由、有效方针和交接。研究中可创作的拟案及时展开，保存节奏按入口“文件与上下文”；不把原料转内容推迟到名为“成案”的最后一步。

第二阶段把有效方针和已有原型深化为约定正文、稿件与工作件，核人员、制作、资源、费用、服务和接口。细节补查在本阶段继续；新证据、关键条件变化，或讨论及原型比较中出现更好的创作方向，都可返回受影响的研究与决定，不限定为新事实。保留仍有效的已核事实及未受影响内容，变动条件定向重核。资源未核不妨碍独立创作，但影响执行承诺时保持条件稿。

| 接入请求 | 当前动作 | 达到的完成点 |
|---|---|---|
| 新项目全案 | 核 A，按眼前的选择准备 B 的审阅实物；开写范围与条件已明确时逐章接笔，到 C 交约定版本 | 各轮只请能决定眼前事项的人作取舍；全案登记实际接收状态 |
| 已有方向继续 | 核方向出处、版本、有效条件和原稿，补本轮缺口 | 已有主线的实质深化，无无关重选 |
| 既有全案修改 | 读原件及变更依据，识别已保留/已废止内容，沿影响修订 | 新旧差异、相关正文和接口一致 |
| 单模块、单条稿件 | 引用有效契约，只取得任务必要上下文与原文 | 本条实际内容及关联状态，无强制全案 |
| 纯研究或审核 | 按声明/决定取得证据，给结论与采用影响 | 研究或审查本身可用，不伪称已完成策划 |
| 真实运行后的反馈 | 先核观察及数据质量，补证并改实际内容/服务 | 可核对修订和下一次观察，实绩与拟案分开 |

收尾、兑现、结算和学习从方案交接时就有责任及条件；它们不是第三个写案审批阶段，也不自动授权外部执行或长期监控。

## 需求、决定与权限

需求描述用户要解决的问题与交付；决定记录由谁、何时、依据何处选定的取舍；事实由原始材料支持；资源与执行以实际回执证明。用户同意估算假设不会把它升级成市场事实。文件变成最新版本不会自动获得用户批准。

重要决定记录：ID、项目/对象、旧值及新值、提出理由、支持与最强反证、备选及代价、决定者与实际权限、来源/消息位置、适用条件、有效状态、受影响对象与重核触发。普通表述编辑不需要独立决定表。

沿现有Brief、原型和重要决定记录，分别保留活动目的、暂定核心体验、已确认硬条件及来源、可调整的实现手段；客户提出的建议未确认为硬要求时不升级。条件或方向变化时说明保留、改变和牺牲了什么及理由，判断核心体验是否仍成立。创作偏好与事实依据分开，不为每个闪点另建决定表。

明确决策、付款、资料提供、资源确认、审核/发布和实际执行接口。同一人可以兼任，仍须看清每项权利。AI职业视角不能创设现实权限、资质、联系人、资源或确认。

已授权的研究、草拟、计算、保存和局部修订在相应节点内持续完成。改变目标、主创意、承诺权益、经营底线、范围或预算时，先给可审阅的改法和影响，由实际有权者作决定。已有有效决定直接采用。外联、发布、采购和付款另按实际授权与回执处理。

## 职业视角及保留的能力

以下是可以由同一AI完成的专业判断职责，不是固定团队人数、固定步骤或角色切换仪式。按本轮问题采用，结论回到同一需求、来源和内容版本。

| 职业视角 | 取得的输入与判断重点 | 应形成的内容/证据 | 易错及纠正 |
|---|---|---|---|
| 市场活动总监 | 委托、对象、读者、负责范围、现实条件 | 适配、范围、深度、主问题和待决影响 | 不只凭活动名定模块 |
| 市场研究负责人/创意策略 | 研究问题、原料、访问能力、已读来源 | 实际查询、事实、正反材料、比较与采用 | 搜索摘要、同稿转载、封面不当全文 |
| 需求诊断/行为设计 | 用户原话、人群处境、阻力、实际所得 | 活动必要性、内容价值、参与动作与退出 | 不推断隐性动机或把“互动”当目标 |
| 增长/财务控制/数据 | 实际目标、预算、基线、可得数据和团队能力 | 适用作用路径、唯一费用、判据及采集 | 不虚构转化率或强制ROI |
| 提案叙事/品牌策略 | 内容本体、受众阅读场景、事实及表达边界 | 连贯活动介绍、母题、单元关系及推进 | 不把主张一句话当完整故事 |
| 创意总监/新媒体策划/跨界导演 | 原料、目标、已有方向、形式与资源 | 具体内容候选或原型、场景/文案、必要比较 | 发散与收敛分开，不为新奇删价值 |
| 项目总监/制片/商务 | 实际内容、资源、合同、技术、费用 | 可承接操作、排产、依赖、交接和失败处理 | 不用“执行方负责”留空任务 |
| 对抗审查/专业与审美视角 | 方案最强版本、真实依据、适用要求 | 根本缺陷、具体修法、补查与复验 | 模型判断不代专业确认或真实反馈 |
| 提案总监/项目经理 | 用途、正文及附件、当前版本和未决 | 可读成案、接手工作件和原生交付状态 | 目录与格式导出不代实质完成 |
| 接收者模拟评审 | 真实文件与其用途，原始来源入口 | 代表接手任务的操作结果及未检范围 | 同历史角色模拟不当独立评审 |

场景只改变判断权重：商业To B重实际买方问题及有需要的销售接收；政企重真实事项、公共价值、身份和适用口径；内部重组织事实、员工所得和参与负担；艺术文化重作品语境与观看；参展重自身展品/接待而不是全馆责任；公益重服务与款物兑现；招聘重真实岗位与反馈；竞标重正式评分和范围；赞助重实际权益。不存在对应目标时不强加销售、公开传播、募资或文化剧情。

## 变更与状态

收到改变先核对象和原因，再看哪些条件失效。记录实际旧值、新值、版本、影响、负责人、下一动作、复核证据。主维护位置修改后，检查被引用的正文、设计、规则、人员培训、邀请/页面、技术/资源、费用、指标窗口及已发布信息；未执行的更正写待执行，不能说已通知。

分别记录适用性、内容成熟度、用户决定、来源验证、资源/合同、文件交付、外部发生与效果。拟邀、已联系、已报价、已确认、已到位不互换；草稿、可评审、已决定、已执行也不互换。运行字段与机械提交依[运行协议](runtime-protocol.md)。

发现重大事实/依据改变时使相关判断、摘要和审查待复核；无关部分保持有效。回滚正文不能撤销已经发生的消息、合同、采购或支付，恢复后重新核当前条件。
