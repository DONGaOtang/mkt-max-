# 条件推演、机会与专业补查

适用：内容或承诺依赖空间、技术、环境、能力、资源、合作或时效；命中专业动作才读对应P节。先读关系与处理链，不把全部专业卡塞进每个方案。专业卡是问题与交接方法，不是法律、医学、工程批准或固定行业规程。

## 从必要条件找关系

从“要提供什么内容/服务 → 必须怎样发生 → 靠什么成立”推导。看单个条件，也看条件同时出现：

| 关系 | 要核的机会/失效 | 对正文的实际影响 |
|---|---|---|
| 人群能力×动作 | 先备知识、体力、感知、设备、社交/操作负担 | 任务、解释、旁观/辅助与退出方式 |
| 内容时长×等待/服务 | 指导、操作、复位、排队及下一环节 | 轮次、分时、内容拆分或服务安排 |
| 设备×环境/使用 | 电力、网络、光声、温湿度、室内外、数据输入 | 演示版本、技术接口与替代呈现 |
| 需求峰值×容量 | 在场总量、单点吞吐、预约与库存 | 招募、入口、等待、候补和满额文案 |
| 日期×档期/变更 | 当前地点、人员、供给、平台/规则及准备时窗 | 场次、提前期、重核与通知 |
| 人手×同时工作 | 服务与采集、切换、休息、转场和专业能力 | 岗位、排班、产能或内容节奏调整 |
| 权益×库存/兑现 | 排他、时段、订单、材料与接收条件 | 规则、权益价格、承诺及退款处理 |
| 传播×实际接收 | 入口、回应、处理能力、目标对象是否匹配 | 实际稿件、接收状态和发布条件 |
| 合作×权限/交出 | 谁能提供、何时交、确认/素材/费用与验收 | 范围、资源状态、Brief和履约 |
| 变更×制作/通知/费用 | 旧物料、已发信息、订单、训练和依赖 | 真正改稿、替换费用及受影响状态 |

条件还提供创作机会：设备限制可发展为可看见的比较，场地本身可提供独特内容，时间轮换可提供新视角，人群经验可成为讨论原料。但机会是拟案，不能把观众反应或未来成果写成事实。

## 补查与处理链

岗位并发、交接、接待能力或信息传递会推翻方向时，执行[同一时序的正常路径、变更及复跑](dynamic-research-and-simulation.md#跟时间和岗位走过一次活动)。用原稿找出第一处无法兑现的承诺，改到原型、相关正文章节和岗位稿，再按同一输入复验。

每项重要问题沿“条件 → 关系 → 机会/失效 → 影响 → 所需证据 → 实际补查 → 选择 → 正文修改 → 复验”。选择可能是保留、改变动作/时序/规模、替换资源、改承诺、延期或取消相关部分。替代须核自己的价值、容量、时间和成本，不能仅填“雨备/备份”就判可用，也不声称替代必然等价。

找实际问题的原始资料和有权专业接口：确认动作性质、主体、地点、时间和适用条款；取得原文及当前版本、核验职能、实际确认和仍缺项。不认识行业仍可生成查询与准确未知，不因卡库缺失跳过；Agent名称/人数不能替代专业证据。仅需静态展示的项目不凭行业名扩展为试用、驾驶或诊疗。

早期案写关键条件、责任职能、缺口和定稿边界；执行案写真实接收、证据位置、放行/停止/恢复和回执。专业确认未取得时只暂停对应专业动作，继续无依赖内容；不编人数比例、气象、技术、医学或动物处置阈值。

## 专业动作共用交接

按实际深度记录对象/动作/时段、条件来源、核验职能及替补、当前状态、证据及版本、交出/接收/时间、停止对象和原因、恢复决定及复验、完成或补救回执。提案填写岗位而无人员时标待指派。模型写出操作卡不代表实际负责人已放行；书面合同、图纸和资格复印件也不自动证明本场技术验收。

## P01 产品演示、真机与复位

命中公开Demo、上手、性能对比、共用设备/账号或个人输入时使用；纯讲座只核宣称。产品/售前核功能和比较，技术核隔离/权限，内容方核屏幕与录制表达。取得型号、配置、固件/软件、环境/网络、输入样本、人工介入、成功标准及不支持条件。

明确工程样机、模拟、预录和现场实测，性能结论仅覆盖可比条件，不借其他版本参数。测试数据及最小权限须实际确认，不默认用真实客户列表，也不收参与者密码。每轮把允许操作范围交体验岗；结束注销、清除个人输入/照片/订单、清洁并恢复配置，复位人确认后交下一轮，以上时间计入产能。

串数据、无法清理、版本不符或断网破坏承诺时停受影响设备/步骤，隔离问题设备，切换已标明的录制/讲解并说明差别；实际复位及重复测试后再放行。会后按已定用途撤权与清理。证据包括设备版本、实测/复位记录、失败、降级与复验；未实测写待核。

## P02 车辆与动态演示

只在试乘试驾、动态性能或驾驶辅助演示启用；静态展车不使用驾驶流程。实际试驾/调度/随车专业人员分别核车、参与者、路线，经营/场地方核适用许可和保险对象、范围、期间及限制。

每轮绑定车ID、车型配置/软件、参与条件、路线环境、陪驾、车辆状态与厂方功能/人工干预说明。接待核人→随车接手→调度记返回→专业人员检查复位→重新放行；换人/车/路线重新核受影响条件。故障、未知条件、超范围请求时暂停对应动作，专业方确认修复/条件后恢复，重算车退出后的轮次、等待和改约。封闭路线结果不泛化全部道路能力，剪辑仍保留条件；不编能源或充电阈值。

## P03 金融科普、服务与推介

命中具体产品、投资话题、交易或机构/专家背书时，由实际机构业务与合规接口确认性质、对象、材料、身份和当前适用要求。先区分知识讲座、一般客户服务、产品推介、交易承接；产品/对象/适配未知时不补造成交路径。

背书仅表达其真实支持范围，不推导保本、无风险或收益保证。运营只交已授权必要资料给专业接收，记录范围和回应时点，主持转交越权问题。科普参与不自动授权营销交易。材料越界、产品/嘉宾更换或身份错误时停对应推介/话术，完成专业重核和已发布更正后恢复。留性质确认、材料版本及问题转交/答复状态。

## P04 健康、筛查与个体服务

命中个体健康信息、筛查、问诊/面诊、医美或疗效案例时，实际承接机构及专业方核动作、人员、地点、设备、范围和适用要求；普通科普不默认加个体服务。未知承接只保留科普/条件方案，预约、专业接手、完成分开计。

运营仅交必要预约资料；专业方负责结果解释、私密交付、异常转介及接手。个体服务资料和营销资料分用途与权限，健康结果不进公开签到表；拒绝营销不影响取得应交结果。未核条件、资料暴露或服务升级时停对应动作，专业核验、补救/通知后决定恢复，模型不诊断或编医学处置。案例影像另核真实性、拍摄条件、用途/渠道/期间，授权不证明疗效可普遍化。

## P05 生产参访与户外路线

命中生产区或受环境影响的路线时，厂方/路线专业方核开放区域、能力、装备、防护、通讯、集结交通、退出及备选容量。厂区保留生产隔离和拍摄/保密边界；户外使用当前确认的路线与时间窗口，天气停开依据当前资料由专业方确定。

出发核实到→各段接手→转组/提前退出有接收→返回闭合。总人数闭合不等于每个人已完成交接。封路、通讯失败、人员去向无法确认或替代失效时停受影响推进，交负责人；重新核专业确认路线、人数、容量、通知和返程后恢复、改期或取消。未核容量的室内/雨备不称可用，相关退款/通知/撤收同步处理。

## P06 展会主办与参展

先分责任。主办核展位库存/分配、展商服务手册、费用服务边界、进撤场时窗、车辆装卸、技术申报和场地/搭建验收；参展核自身展品、人员、演示、物流、物料和接收。兼任仍分职责。

招展承诺→资料→场地/技术接收→进场验收→服务→撤场检查→损坏争议与结算，每段有实际接收和遗留项。展位变动同步用电、导视、名单、权益和通知。未通过相应确认时停该展位相关搭建/使用；撤场冲突交总控。修复经实际责任方复验再恢复，不以展商自述替场地验收，参展方案不能承诺全馆票务和安保。

## P07 节目、演职与权利变更

命中表演、演职主体、技术需求或录制传播时启用。先核性质，不将全部内部节目等同一种经营性演出。制片、技术、权利方和适用要求核验人各核其职责。

节目/主体、合同及技术需求、走位/时长/切换、设备和彩排、作品/表演/直播/回放/剪辑权限分别有当前版本。制片交技术内容和cue，权利方交可用范围，总控收实测彩排结果。换演员或节目同步技术、权利、提交资料及观众服务，未核变更停对应内容；新版本实际复验与必要通知后恢复或用已确认内容，不只改分钟数。

## P08 赛事、评奖与申诉

只在竞技、作品评选、挑战或奖项时启用，趣味互动采用必要规则。实际负责人、裁判/评审和申诉接收分别定位，利益冲突和回避要可处理，申诉不只交被投诉者。

锁规则、资格、器材/软件版本、赛程/休息、评分/同分、作弊证据、奖项库存、申诉时窗/渠道、改判和公示。核资格→裁判接条件→保存原始成绩/作品→申诉处理→确认排名与兑现。中断、补丁/器材/路线变化按赛前规则处理，不能无记录改权重；恢复说明已赛、未赛和公平影响并通知。专业场地/技术另核真实要求，不编统一赛制，原始成绩与裁决依据可追。

## P09 公益与募集款物

按实际是否募集分流。无募集的项目核真实受益对象和服务边界；一旦增收款码、募集实物或资金动作，重核主体/合作角色、账户、用途、方案及当地现行适用要求，不能沿用原体验放行。

实际项目、机构与款物负责人维护参与/募集→登记→实收对账→受益接收→使用/交付证明→披露与异常。受益身份控制访问，款物流与传播授权分开。账户、用途、伙伴变化或账物不符时停对应募集/拨付，核验更正与通知后决定恢复。未交付不能靠热搜判目标达成；意向书、合同、到账与服务结果分别表达。

## 动态重核

日期、地点、内容、价格、预算、人数/容量、人员、技术或权限变化，沿受影响依赖重核。报价、预报、档期、账号和资源记录有效对象/期间；原文件指纹相同不能证明今天仍可用。把修法写回正文、规则、任务和承诺，再检查联动；不能只在风险章新增“加强管理”。参与服务的具体操作见[执行与复杂度](execution-and-complexity.md)。
