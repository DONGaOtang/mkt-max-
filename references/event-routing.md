# 怎样分流一份活动简报

先辨明这一次要完成的工作。有人等着决定一件事，就找出这个决定、能作决定的人和足以让他判断的材料；在构思活动内容时，再判断谁为什么参加、将经历什么。王春雷、陈小连区分举办理由与各方预期结果，《Event Design Handbook》分别考虑各方的投入和预期行为变化。下文是本项目对这些方法的应用。[书目与原书页](event-planning-books.md)

## 先定本轮委托

| 拿到的委托 | 现在交什么，停在哪里 |
|---|---|
| 新项目，或还在决定是否办活动 | 用原话复述对象、想解决的问题、成功依据和本次交付，提出初步主线。进入 **A 确认委托**。若办活动的必要性存疑，写出能解决同一问题的更简单做法及其代价，请人决定是否继续研究活动。 |
| 已有方向，要深化或修改 | 读现稿、有效决定和本次改动。写出受影响的内容。事实、对象和目标仍成立时直接接续；改动推翻主次时，只重开受影响的决定。 |
| 只写邀请函、只核费用、只审一句主张等局部任务 | 有明确依据与足够输入，就交约定的实际稿件或核查结论。所缺信息若会改变文字或判断，说明可写部分和一个决定性缺口。局部工作本身不触发整案审批。 |
| 只要常态投放、改网页或查资料，委托未包含活动 | 回到实际用途，提供文案、判断或研究等受托成果。限时线上征集、公开课等有具体参与内容的任务仍可按活动办理。 |
| 还没有主张，希望助手找机会 | 从已有访谈、产品、服务现场或当期市场材料找出一个原来没被说清的选择。例如，谁改用哪种替代做法、为什么放弃原有入口。交原始线索、可以发展的想法、它可能在哪种条件下失效，让主创接着写。已有说法需要核实时再按[动态研究](dynamic-research-and-simulation.md)复核。 |
| “做个有声量的活动”等信息不足的简报 | 找出未知是否足以改变路线。若对象也未知，问“这次最希望哪类人来，他们来了要得到什么？”若已有两个合理解释，写出各自会带来的不同活动，让人选。候选标“待确认”。 |

## 按眼前决定找人和交稿

先用一句话说清谁须在何时决定哪件事，以及选错会失去什么。只查会改变这个决定的职能；能从现有委托、原件、报价或已核记录取得的材料，由助手先取。职能名用来定位信息和责任，拍板权依本案实际授权。下面是可单独选用的做法。

| 何时需要谁 | 他能确认或决定什么 | 交给他看什么 |
|---|---|---|
| 市场负责人、事业部或预算持有人要决定是否投入、挪用或停投 | 持权人决定投向、规模及经营取舍；市场负责人协调目标冲突 | 给一页同口径比较：本次目标、维持现行做法或暂缓会怎样、改投活动多得到什么、挤掉什么；标出推荐和能令它翻转的证据。现金支出与被占用的人手或渠道时段分别计算。 |
| 需求未明、对象可能改变，或两方对效果的定义不同 | 洞察人员核研究对象和证据范围，数据负责人核基线、去重和可测性，主创或业务负责人取舍目标人群与内容 | 给实际选择或流失的一例及来源，对照同档期替代品、时间或支付意愿、接触入口；写明已观察到什么、哪一点需拿真实对象试。 |
| 创意负责人在选表达，品牌或产品团队须核一个差异 | 主创选择原句与体验做法；品牌负责人核定位与表达，产品责任人核事实、适用条件和证据能支持的说法 | 给主创看原段与试写，给品牌或产品看一句对外主张、原件及读者可能误解的一处；材料未齐仍可打磨内部样稿。 |
| 招募、预约或交易会用掉业务接待能力 | 销售或客服确认谁接、能接多少和何时回应，CRM 或数据负责人核匹配、重复及来源口径 | 用一条记录走完入口、判断、分配、接收和满额处置，写明既有业务、可归为新增的部分和仍未知的量。容量供排班；估算新增要另有证据。 |
| 区域门店、经销商或渠道须投入本地资源 | 由实际掌握资源者确认可用班次、库存、核销和售后；区域意见只覆盖其负责范围 | 给该地区或门店一份具体交接，查人手、时段、当地替代活动、常规顾客受何影响，以及变更如何回传。 |
| 媒介、公关、社媒准备交版、发布或更正。具体说法或素材涉及专业审查时才引入相应责任人 | 产品或权利方核事实和使用范围，有发布权者决定渠道、版本与时间；截稿点只决定何时交版 | 给渠道看可用稿、仍待核的一句及其替代，标出已发、待发和需第三方回执的触点。 |
| 制作方式、采购条件或现金风险可能推翻创意或投资 | 制片和供应方在选方向前提供可行做法、初估及期限；采购与财务分别核报价、合同和现金约束，下单按实际授权 | 给两个可选做法及差价、不可退支出、锁定时间、少做什么；仍待确认的费用留作条件。 |
| 项目依赖赞助、伙伴资源或联合履约 | 各方分别确认自己能投入的资源、交付的权益与想取得的结果；负责人据此决定承诺不足时能否开办 | 给双方看同一项合作各自投入与所得、谁接需求、怎样验收权益及观察业务结果，以及承诺落空时如何缩减或暂缓。 |

只要一段体验、一个闪点或一项核查，直接交相应成果。多人同时给意见时，把各人的原话留在它能决定的范围。先办已获托且可逆的研究、试写或核算。对会改变公开承诺、支出或执行的缺口，指出最迟何时要哪位责任人确认；不为一张分流表逐岗找人签字。

收到更正，先指出**原先推荐依赖的哪一项判断变了**。例如，原计划为全期配人的伙伴后来只确认首场有人，就回到其他场次的资源与投入比较，交负责全期预算的人决定缩减、换做法或继续。写明哪些收益还能成立、仍未知什么、什么新凭据足以再议。独立成立的创意选择及主创原稿继续保留。沿实际关联查到正文、工作件及已经发出的承诺。[变更后的写作](author-and-chapter-writing.md#一条条件改变后怎样回到整份方案)

## 用什么判主线

1. 从有效简报、访谈或既有决定中摘出**主办目的、参加对象、对象愿意来的理由、现场或线上实际发生的动作、判定依据**。参加者、受益方、出资方可能是不同的人。原话和策划推断分别写。
2. 追问“即使其他环节都做成了，少了哪个结果仍会让负责人判断这次没办成？”用回答提出主线，再判断辅助动作有无委托、谁接得住。项目名、渠道、需要查证的事项和营销术语均不能独自决定主线。
3. 标明委托责任（主办、参展、协办、内容承制等）、单场或跨期、线上或线下及必要的双方接口。同一场线上直播既可用于观看，也可用于教学或交易；渠道只改变参加方式和执行条件。多期需要共享内容、反馈或资源时启用[系列统筹](series-orchestration.md)。
4. 若本轮在选活动内容，从下表找贴近该动作的研究问题和第一段正文。也可以写表外动作。若本轮只决定投入、口径或履约，先用上节的比较或工作件，已有内容仅取会改变该决定的原段。行业事项见[类型契约与场景补漏](requirements-and-adaptation.md#类型契约与场景补漏)。

| 主线和选择依据 | 先研究什么 | 第一份能读的内容 | B 选择方向时，请人判断什么 |
|---|---|---|---|
| **体验或欣赏**。亲自听、看、试，才能感到或理解某个差异 | 真实作品、样品、使用场景、普通人能感知的差异和展示条件 | 写出一个参加者从进入、观察或尝试到发现差异的完整片段，可附一段导览词 | 这个发现是否值得到场？去掉舞美还能感受到什么？ |
| **学习或练习**。参加者要能自己完成一件事 | 起点能力、典型错误、示范原料、反馈方式和练习机会 | 一道完整练习、示范做法、合格完成物和一次反馈 | 能否凭作品或操作看出参加者学到了什么？ |
| **仪式或认可**。要共同见证一件事、承认某项贡献或交接身份 | 真实事项、贡献依据、当事人表达意愿和必要礼序 | 一段含具体事实、说话人、见证动作和当事人选择的仪式文字 | 谁被承认、为什么、由谁表达？当事人是否愿意这样出现？ |
| **交流或对接**。两方需要交换经验、判断或合作意向 | 双方各自带来的问题、可交换的内容、配对条件、会后接收方 | 一轮有具体问题、追问、回应和结束方式的对谈或会面 | 双方各得到了什么？是否有理由见第二次？ |
| **服务或公益**。受益者要实际办成一件事 | 真实需求、服务资格、单次耗时、容量、例外和接收岗位 | 一份受益人能读懂的服务说明，加一次从进来到完成的处理过程 | 怎样知道服务兑现？满额或办不了时谁回应？ |
| **传播或公开发布**。公众要知道、理解或转述一个真实变化 | 待发布的事实、证据和授权，目标读者原有认识、信息触点 | 一段能公开读的核心说明和一个证明它的现场或线上内容片段 | 读者能否准确说出变化？哪些承诺需要删改或待核？ |
| **转化或交易**。委托明确要求预约、申请、下单等后续行为 | 对象的选择问题、品项和条件、接收方、容量及后续履约 | 从理解条件到自主选择、被接收及得到反馈的一轮实际流程与文案 | 人为何愿意行动，谁有能力兑现？ |
| **赛事、评选或征集**。完成任务后需按约定规则判定结果 | 真实任务、资格、评判依据、裁决主体、申诉和兑现方式 | 一段完整参赛任务、判定实例及结果通知 | 同一份作品能否得到一致判定？争议谁处理？ |

## 混合、冲突与未知

- **有主次。** 在同一份简报中写清依据，保住主线，说明可以削减的辅项、损失以及先写哪段样稿。只有明确约定传播或销售时才派相应任务。
- **两项目的都必须达成。** 分别列出参加对象、核心动作和判断依据。如果可以在同一环节兼顾，写出这个环节及两种完成条件；若争用人手、时段或预算，给两种实质排法，各写明代价、建议和需要谁拍板。无法调和就保留冲突，等实际负责人决定。
- **未能判断。** 写出最能改变判断的一条缺口。能区分两条路线就给一个有后果的选择题。连对象都不清楚时，不为了制造选项发明人群。等待答复期间只做已经委托、各候选都用得到的工作。
- **人的决定和判断置信度分别表达。** 对象、目的、动作和优先级都有直接依据为高；主线有依据但依赖关键假设为中；多靠推测或存在冲突为低；无从区分为未知。分流建议无论多有把握，均须等有权者明确确认才能记入既定范围。已有确认注明出处并沿用。人纠正后同时改研究问题、首段样稿和审核问题。

## 同名简报，实际怎样发给策划人

以下均为此次编写的虚构片段。三个委托都叫“剧场开放日”，活动名称完全相同。

| 委托人的原话 | 分流建议及随后的稿件 |
|---|---|
| “我希望没坐过剧场后排的人听出，不同位置为什么听到不同细节。” | 建议以听觉体验为主。先验证两处座位是否真的听得出差别并核开放条件；首稿写同一句台词、换一次位置、请观众指出变化。若现场差异不成立，请主办改场景再选方向。 |
| “明年要找能带读的新志愿者。这次想让新人独立带完一段朗读，得到一次反馈。” | 建议走学习路线。先问新人的起点、谁给反馈、如何认定带完；首稿写一段具体带读任务和导师的反馈。审核聚焦新人能否独立完成。 |
| “是向做满十年的幕后同事致谢。希望家属知道他们做过什么。” | 建议走认可仪式。先核可公开的贡献、本人愿意如何出现及家属能听懂的事实；首稿写一段真实贡献引入、家属见证和本人可选回应。由主办与当事人分别核事实与呈现方式。 |

若简报只写“剧场开放日，接触新观众，也希望找到志愿者”，首轮可以这样说：

> 一种做法是让第一次来的人走进后排，听同一句台词换座后有什么变化。另一种做法是把这段时间交给准志愿者，让他们试着带一位观众完成体验。若当日人手只能支持一组，您最希望普通观众带走一次发现，还是看到哪些人愿意继续做志愿者？这个决定会改变我们先找哪类人、先写观众导览还是试带任务。

拿到“这轮只做公众体验，招募另议”后，先复述这项更正，转查可感知的差异、座位条件与观众参与负担。若对方接着只委托写入口提示，则交可直接使用的提示文字并注明待核位置，不额外生成招募表或全案。待讨论稿、客户正文与执行件的具体写法见[写给真实读者](reader-delivery.md)。
