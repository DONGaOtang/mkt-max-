# 实质内容、叙事与创意质量

适用：开发主题、主张、活动介绍、单元、体验、机制、概念案、稿件或修订已有内容。先读原料到正文与单元；需要叙事、创意发散、规则或质量比较时读相应节。不把Slogan、剧情、互动、图片或传播设成全部项目配额。

## 原料到正文

先取得本项目的产品证据、作品、知识、真实问题、人物本领/经历、地方材料、组织事实和服务，不只搜漂亮外部案例。每项采用原料明确来源与实际可用状态，然后形成“服务谁 → 具体所得 → 内容如何提供 → 对象看听做什么 → 怎样开始发展完成 → 成立条件”。真实原料要核，艺术转译和新创作标拟案，受众反应/效果预期标假设。

研究结论须改变内容：取一项采用事实、视觉观察或反馈，写出相应代表场景、提问、任务、标题/段落、脚本或制作Brief。内容已约定全量则完整生产，不能用代表稿折抵。原料不足区分事实缺失、作品/人物未取得与创作尚未开发；在授权内提出具体拟案，不能全部推给“主创/嘉宾后续深化”。

## 主要正文模块

按需求启用与读者组织，不复制固定目录：理由与主张要连接真实内容；市场依据解释影响而不堆资料；命名准确指向内容；Slogan仅在需要时提炼能兑现的表达；总体介绍写清内容结构和单元关系；活动信息写当前事实和入口；规则写可操作步骤/判定/结果/限制/异常；人员、文案设计、执行服务、传播、成本、测量收尾和替代有实际工作件。标题可前置展示，创作不强制先取名。

完整概念案用连贯正文讲活动是什么、原料与价值为什么成立、主要内容怎样开始/发展/结束、观众怎样进入和收获、必要参考/视觉方向及核心待核。它不是删掉预算的执行表。概念内容可审阅不等于采购可下单、剧本定稿或资源已落实。

## 叙事与内容关系

一句主张只是入口。用实质段落解释面对什么处境/问题/材料、为何此刻组织、观众以何种角色进入、实际遇到哪些内容/变化、最后获得什么回应。以具体逻辑替代“串联、焕新、共鸣”。选择适合原料的连接：

| 连接方式 | 应出现的内容推进 | 空泛替代及纠正 |
|---|---|---|
| 论证 | 具体问题→证据/演示→回应疑问和限制→支持判断 | 议题名/产品形容词要改成实际论点与证据 |
| 体验 | 理解入口/规则→可察觉变化→理解、能力或作品 | 分区/打卡名要改成看到或完成的东西 |
| 关系 | 共同处境→真实贡献/需求→认可或连接→有需要的后续 | 强破冰/煽情要改成具体交流内容 |
| 时间 | 关键事实变化→有证据的转折→现在与下一步 | 年份照片堆积不能冒充历史因果 |
| 空间 | 入口理解→各点独立发现→路径/对照→可选择收束 | 箭头和集章不代展项内容 |
| 剧情 | 人物处境/欲望→行动阻力→选择转折→结果余韵 | 诗意命名和高潮图不代完整故事 |

并列作品可直说不同视角，不强编因果；稳定庄重感受、安静观看和专业理解可以成立，不强造高潮、敌人或掌声。预期理解/情绪变化说明由什么具体内容促成，真实反应只有发生并取得记录后填写。

文化/艺术/地方项目说明作品、场地、历史和生活材料的真实关系，出处事实、艺术转译与虚构设定分开。无原始证据不把新创作挂成地方历史，未知作品不代真实作者编情节。非文化项目可用通用叙事，不套海边、精神社区或某著名目的地气质；预算和形容词不足以证明场景适用。

## 核心单元完成

每个主要单元须让读者讲清：是什么/为什么设置/服务谁，实际看见听见或做什么，如何进入、推进和结束，获得什么，与其他单元的区别与关系，依赖及失败处理。首次到访、中途加入或只看一个单元时能否独立理解也按需要说明。

深化时在现有“看/听/做—所得—目标”描述中，分开写设计意图、预安排人员的行动和真实对象可能的响应。说明对象为何愿意且能够采取关键行动，哪一步可能失效，以及怎样补足、试验或替代。安排人员行动不能证明顾客响应；主题词须落实为具体内容、人物关系或可感知变化，不能凭标签判定已表达，也不为套词强加观众互动。

| 内容类型 | 当前用途须读到的实质内容 |
|---|---|
| 演出/戏剧/展陈 | 策展命题或故事、人物/材料关系、主要场景/展示对象、关键变化、结束，代表段体现表达方式 |
| 演讲/汇报 | 具体主张、论点顺序、每个证据/案例/演示、反方疑问及限制、结束后的判断；嘉宾未确认观点标拟稿 |
| 圆桌 | 具体讨论对象、真实分歧、能展开的实际问题与追问、不同角色回应理由、保留分歧的收口；不预编回答或共识 |
| 闭门交流 | 共同问题、可提前读的事实、交换内容、讨论顺序、记录/引用边界和后续接收；不只写某保密规则名称 |
| 产品/技术演示 | 使用情境、输入与条件、动作、可观察输出、可比口径与限制、失败替代；无实测时交验证设计而非胜出结果 |
| 工作坊/培训/共创 | 真实任务、输入/材料、示范、操作顺序、检查反馈、完成物样例/判据、离开后能做什么；白表不等于学习 |
| 仪式/纪念/表彰 | 真实事项/贡献、人与物关系、动作意义、完成状态及结束；象征不创设资格，口号不代事由 |
| 导览/游园/独立观看 | 每点实际内容、发现过程、路径选择和必要前情、未走全程的独立所得；不强制集章才有体验 |
| 商业/合作推介 | 对方决策问题、价值来源、合作条件、成本风险、真实证据、未决和可选下一步；意向、合同和到账分开 |

没有固定字数、问题数或环节数；数量要足够完成本次内容。概念阶段写可审原型，评审阶段覆盖完整核心，执行/制作按约定补逐字稿、任务材料、主持/导演台本或演示文件。只有标题、时长、人数、“沉浸互动”或“嘉宾分享”视为内容缺口。

当本次承诺教会一项操作，核训练材料是否足以演示核心动作及反馈；只有缺失例而没有完成动作所需输入时，可在已授权创作范围明确拟制教材回包、正例和参考完成物，始终标模拟，不能伪装真实来源或结果。若本次目标就是判断缺口/补查，可以据未知完成，不强补数据；若承诺写出有效通知、更新或操作结果，仅反复标“未知、待补”不能算该动作已经演示。未能演示的技能明确保留，不能把这项按需补查变成所有活动固定环节。

衔接落实到上一段留下的问题、信息、道具、成果或空间提示，下一段怎样接住、转场谁做什么。主持须给本次实际开场定题、中段追问、结尾收口的拟稿；主持词不能替内容补缺失逻辑，也不必把分歧收成一致。

## 创意的可变范围

先从主创原稿和本轮答复识别必须保住的内容、现实硬条件、允许试验的表达或机制，以及仍待讨论的部分。主创未作取舍时，几个念头各留原段和理由；助手可以补材料、尝试转译和试写，回交后让主创继续发展。行业、年龄或“沉浸”等标签只提示研究方向，不能据此决定参与负担、审美或玩法。游戏从业者也可能希望轻松观看和自由休息，是否需要复杂规则要回到这次参与者的处境与所得。

新做法要说明它具体改变了谁的动作、得到什么、需要哪项真实资源、付出什么代价。保留现有可靠做法作比较对象，替换它须展示内容收益及损失。创意小样和图稿按本轮约定的比较需要制作；候选的数量、命名、形式和表达长度随内容需要确定。

## 创意发散与收敛

方向取决于人是否看懂、愿来、愿继续或愿再来时，拿实际原型按[参与者的选择过程](dynamic-research-and-simulation.md#跟同一个参与者走过几个决定)走一遍。把本案的一次分支写进讨论稿，让主创看到哪处提示、参加方式或退出办法值得改变，以及选中以后要观察什么。

先把作者想保住的体验写成一幕：某个人在哪里，因为什么停下，接下来发生哪一件有意思的事。讨论时先帮助作者把这幕展开，再对当前原型的一处关键假设给反证或实际改法，交主创补写和判断。若两案都争用同一位讲者、一段开场或一件道具，写出各自怎样使用它、各自放弃什么；随后交 B 由人选择。没有实质分歧时，一段原型及成立条件可以供人讨论。用户说“先别选”时保留并存方向和下一研究问题。局部试写按明确范围完成，选择某个创意后仍须有相应接笔委托才写正式章节。

本轮明确继承的方向作为当前基线，深化、分叉或重新选择按[工作流与决定](workflow-and-decisions.md)处理；无方向时先从项目原料和目标锁锚点，再按缺口选可变域：当前相关问题/热点情绪、文化记忆、已得人群情绪、跨界机制、感官、真实张力等。嫁接、双域或多域碰撞用作生成，不硬编码域数量与候选配额。

横纵比较供给可用信号；将原始材料拆成事实/观察、底层信号、可用动作、失效边界，再与项目资源碰撞。可尝试反转真实不便、借不同行业解决相同需要的机制、改变表达权、感官或时间结构；热点必须相关且可核，不能贴名字，跨界不能照搬或破坏核心证据顺序。

发散与评判分开。先保留主创提出的原段与足以比较的候选，给每种做法最强的成立理由。比较目标、人群所得、原料、独特性、条件/成本和持续能力后，带着判断和代价交主创决定保留、修改、暂缓或继续探索。心理理论仅是触发条件、边界、反例及待验证行为假设，采用理论具体结论时回一手出处；不能凭“稀缺、峰终、社交货币”等词保证本次反应，不能编假稀缺或只写高潮。

候选卡可简明写名称/概念、实际依据、具体内容与动作、所得、与常规差异、为何可能成立、关键假设/核验、依赖和失败边界。卡是方向工作件，入选后按本轮委托完善原型，并将原稿、取舍和研究发现整理给主创确认接笔范围。章节按逐章或明确批量范围写出并回交审阅，文件名称须对应实际内容和用途。

## 机制、规则与真实一轮

实际含任务、票券、积分、排行、闯关、抽奖、投稿、共创或交易时，从原始机制拆动机、投入/所得循环、开始条件、选择/状态变化、成功失败、退出、奖惩/兑换、判定争议、素材/数据、失效及本项目替换。用本案拟定规则走一轮具体过程，模拟值标假设；互动不是全部活动的必需。

规则写资格与入口、时间、投入动作、限额、具体判定、结果/权益、限制、重复/作弊/同分、未入选、争议、退出及中断处理。票券/奖励核发放、消耗、库存、核销/释放和结束结算；奖励不掩盖空内容。吞吐计指导、操作、复位与工作人员占用；权益可兑现才承诺。规则变化同步文案、培训、物料、账号/系统、资源、费用及公开信息。

## 创意、审美与辨识质量

收敛与成案时核八种问题：能否复述实际内容、是否有项目专属性、对象投入是否有真实所得、本次场域价值、适用沟通的可转述事实/观点/画面、约定资产能否长出内容、审美/身份是否适配、执行接手是否知道准备和完成什么。这是判断面，不是八种必加玩法。

去掉名称、包装、图片和主持修辞后，读者仍应知道实际内容及其关系。常规演讲、观看、仪式和复演可有价值；新奇也可能空洞。换品牌/地点后仍完全成立，要核原料、空间或服务的真实作用，不只加Logo。命名/Slogan应准确、可理解、与正文和服务一致，不用夸大或空洞祝福替内容。

审美核本次品牌、人群、行业、价格带、场景和反馈，检查身份压力、社交负担、仪式、文案、视觉与服务；年龄/职业/消费能力不单独决定偏好。“土、廉价、高级、网红”须翻成具体画面、材质、光声、话术、任务或阅读问题及改法，未有样本标创作判断而非共识。参与者不愿拍摄、社交或公开时仍能取得承诺核心体验。

若目标包含项目认知/目的地/到访，核实际稿件组合里人物、活动、项目和地点如何关联，受众是否明白为什么在这里、现在能获什么和怎样开始；各稿可分工，不强每条塞地址。采用接近真实接触顺序的无提示反馈，记录对象、材料版本、覆盖和原话；没有目标用户就只称桌面检查。仅记明星/装置或曝光高不能证明项目记忆提升。

人物和正向传播用具体场景解释真实本领→内容任务/选择→可见变化→受众可有自己的话→实际证据。拟人物/剧本可创作，履历、技能、引语、现场反应和自然好评须核；拍摄失败和没有扩散时内容仍需兑现。生产图/实际文件见[人员与设计交接](staffing-and-design-handoff.md)，最后按[对抗与验收](adversarial-and-acceptance.md)回读真实正文。
