# 写给真实读者

先确定谁会打开这一份稿，以及读完要作什么决定或完成什么动作。供策划人选择方向时写讨论原型，供委托方审阅时写连贯的客户正文，供岗位接手时写操作件。只交本轮约定的材料。进入 **C 审阅交付** 前，实际打开文件或回读聊天里的完整正文，按文末动作走一遍。

## 三种读者，三种写法

| 谁读、何时读 | 实际写什么 | 写完如何检查 |
|---|---|---|
| 正在 **B 选择方向** 的主创或业务负责人 | 按[具体决定](event-routing.md)给一份看得见差异的材料。主创可以拿一幕推敲；预算负责人可先看同一目标下两种资金用途；发布负责人可直接读待核的主张及依据。 | 单读能说出选什么、牺牲什么、什么证据会改判。对方只选了其中一项时，在实际回复范围内接续。 |
| 委托方、预算或内容负责人，正在审阅成稿 | 体验稿从参加理由和现场过程写起，再写如何兑现。资源取舍稿从建议与替代用途写起，给增量依据、资源代价、未决项和继续投入的条件。按约定附明细。 | 决策人能据稿选择继续、缩小、更改或暂缓；读者能定位决定所依赖的条件。 |
| 主持、制作、服务、采购等接手人，准备按稿工作 | 单独写给相关岗位。给实际版本、动作触发、输入、要说的话或要交的东西、完成标准和异常去向。需要打印的卡片给全部字句；受托做全套须写全。未核时间、地点、资源或承诺留明示条件。 | 接手者能从起点走到完成，并知道遇到一种常见异常怎样办。需要自己再编规则、台词或结尾时，退回补稿。 |

苏海《活动策划实战攻略》第二章分别展示了总体方案、预算、分工和活动当日流程；Matthews《Special Event Production: The Process》第一章讨论了从初步提案到具体制作的条件。这里把同一内容按接收者要作的决定和操作分别写出。章节与试读见[行业书目第四、五节](event-planning-books.md)。

交研究或局部文案时可用更短的形式。研究稿先写影响当前决定的判断、依据和反例，再给来源与未决。用户只要一段招募说明时，先给可复制的全文，必要的待核信息单列供作者处理。版本记录、调研日志、任务状态和内部反证留在工作档案里，客户需要知道的限制写进相关正文。

## 同一个单元的三份实际文字

以下为原创虚构委托。某公共出行体验课希望让第一次独自乘公交的人学会看方向。委托范围仅为一个三分钟的模拟站牌练习。下文的两张站牌、站名和时长均为教学设计。印制和带领岗位仍需主办落实。

### 给策划人的讨论原型

> 来的人会遇到两张都写着“木桥”的站牌。他想去云台，究竟站哪边？一种做法是引导师先指出发车方向，大家跟着找到云台，优点是初学者不容易卡住，代价是我们看不出他能不能独自选对。另一种做法是先让他选，然后问“在你选的这张上，车经过木桥后，下一站是哪儿？”选错也能沿箭头亲手改回来。
>
> 我建议用先选再讲的做法，并留一次反向选站的机会。若这三分钟的目的只是让排队的人快速看一眼，那么先示范更省时。您要保住的是独立判断的机会，还是让更多人看到示范？这个取舍会决定讲解发生在选择之前还是之后。

下两份文字演示主办选择“保留独立判断机会”以后怎样展开。在真实项目里，该选择须来自有权者的实际答复。

### 给委托方的连续正文

**《哪边等车？》模拟站牌练习**

找到正确的站名，还要判断车往哪个方向开。这个三分钟练习把这一刻单独提出来。参加者站在两张模拟站牌前，两张上都有“木桥”，桌上的目的地卡写着“云台”。他先选自己会去等车的那一边。引导师请他找到“木桥”，顺着箭头读出下一站。如果读到“溪园”，就转到另一张牌前看一眼。改变选择本身就是练习的一部分。

第二次只换目的地。人还在木桥，这次要去溪园。参加者再选一次，并指出支持自己判断的下一站。第一次靠运气猜中的人，也有机会在这里说清选车的理由。两次都可以用手指回答。旁观者也可以先看完一轮再决定要不要试。

这一单元拟用两张反向站序牌、两张目的地卡和一名引导师。主办须在开课前确认有人带领，并试印核对箭头和站名字号。模拟图用来练习读懂行车顺序；若课件要换成当地线路，须先核实当地站牌的方向标示与实际站序。

### 给引导师的执行工作件

**《哪边等车？》引导卡 · 三分钟一轮 · 试带稿**

开课前按下列字句制两张模拟站牌。把两张牌并排放好，用相同标记标出“木桥”。把目的地卡叠放，先“去云台”，后“去溪园”。引导师先试读，须能看清每个箭头、两个终点和“木桥”的位置。印制及当班人未落实时，此卡供试排。

| 材料 | 实际字句 |
|---|---|
| A 牌 | 开往松湾　溪园 → **木桥** → 云台 → 松湾 |
| B 牌 | 开往溪园　松湾 → 云台 → **木桥** → 溪园 |
| 第一张目的地卡 | 你在木桥。你要去云台，在哪边等车？ |
| 第二张目的地卡 | 你还在木桥。这次要去溪园，在哪边等车？ |

| 相对时间 | 引导师具体怎么做、怎么说 | 怎样收住这一段 |
|---|---|---|
| 0:00–0:45 | 亮出第一张目的地卡，说“先选一边。可以指出来，也可以先看。”等对方选择。 | 指出 A 或 B 都继续。愿意旁观时，自己按下段示范。 |
| 0:45–1:30 | 说“请指到木桥，沿箭头走一站。你指到的是哪里？”选 B 的人会指到溪园，邀请他换到 A 牌重新走一次。 | 对方能在 A 牌上用手指从木桥走到云台。看不清字时，逐项读给对方，由对方选择。 |
| 1:30–2:30 | 翻出第二张卡，说“出发点相同，这次你要去溪园。该换到哪边？什么让你这么选？”对方只想观看时，自己指 B，沿箭头从木桥移到溪园，念出两个站名。 | B 牌的下一站为溪园。对方仍选 A 时，一起从 A 的木桥走一站，再让他自己改选。 |
| 2:30–3:00 | 请愿意作答的人指一指最后选的牌，说“找出现在这站，再沿行车方向检查目的地在不在前面。”收好卡，将“去云台”放回最上方。 | 独立选到 B 且指对下一站，才说明这次独立判断成功。选错后能改正，可记作在提示下完成。旁观者看完即可，只作当场判断。 |

## 让读者实际走一遍

- **讨论原型。** 只看讨论稿，能否指出需要取舍的是讲解和第一次选择的顺序？“看起来不错”不说明选择了哪条路线。若答复只说“要快一点”，应明确缩短哪一步和会损失什么，再交人定。
- **客户正文。** 遮住岗位卡，让读者复述第一次与第二次的不同、参加者怎样知道自己选错、主办要准备什么。若读者只能重复“沉浸、赋能、互动”，回到段落补实际动作。模拟阅读只记为桌面走读；真正让委托方阅读后才登记其反馈。
- **执行件。** 照卡摆出 A/B 牌，依次走“首轮选错 B”“第二轮正确选 B”“只愿旁观”三种情况。分别查台词、修正机会、结束和复位。任何一步需要临时发明材料或规则，就补写这张卡并重走。
- **跨稿一致。** 核参加对象、主目标、材料、动作顺序、时长、人员与条件。人若选了先讲解，讨论记录、客户第一段和岗位卡第一步都要更新。可读、能试带、已获主办通过、现场验证过四种结论分别记录，注明实际发生了哪一种。更多验收方法见[对抗与验收](adversarial-and-acceptance.md)。
