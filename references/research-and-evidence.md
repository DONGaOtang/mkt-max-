# 研究、来源与证据充分性

适用：查询、事实核查、案例拆解、原料取得、参考图观察、预测依据或交付对标。读取对应问题、关键词、来源与充分性节；没有研究缺口时复用有效材料，不默认联网或扫平台。

## 研究问题与接入

档期、资源、价格、平台能力或市场反应会改变眼前取舍时，执行[检索并复核会变化的条件](dynamic-research-and-simulation.md#检索并复核会变化的条件)。当场提供实际取得的当期依据、适用时间和采用判断；发生变更时，给出原值、新值、可比范围和已经改好的正文。

先读原需求和已有产物，区分原始Brief、用户陈述/决定、历史方案、历史实绩、当前拟案、截图/影像与原生源件。核对象正式名、别名、主体、年份、发生/发布/访问时间、原件版本、确认状态、计划或实绩、当时条件、缺页/冲突及使用范围。同名项目先消歧，旧报价/阵容/场地/规则不能自动当本期确认。

研究从当前构思疑问、原料探索或取舍出发，说明什么信息可能改变哪部分、已知与未知及获取路径；想法未成形时不强迫先列完整候选。信息源可来自人的行为、日常生活、空间、作品、其他行业及同类活动；说明实际材料中哪个细节值得借鉴、如何转译、可能改变当前构思的什么。区分事实、推测、创作偏好和待验证效果；同时寻找可能削弱喜欢的创意的材料或替代解释。每次检索落实到实际查询、入口、时间和筛选；不只交“查小红书、找国外案例”。纯研究任务交判断及内容影响；含创作委托时将已采用原料变成具体拟案。

已有档案按“本轮保留/改写/弃用/待核—理由—影响对象”接入。原方案写过的事实仍须来源支持；往届主办自报不自动证明增量。需要用户内部资料时先明确资料对象、持有方、用途、截止、缺失处理与真实权限，写成请求草稿；无外联授权不实际发送，无回执不说已联系。

当缺口是专业判断，可按问题直读[活动策划专业书籍与产物改法](event-planning-books.md)。书页解释一种判断为何值得做，项目证据回答该条件在此处是否成立。例如，书中关于参与代价的讨论会促使策划者考虑缩短准备工作。参与者能否腾出半天，要从当期访谈、班次或报名反馈取得依据。草图可先写明假设和一个可讨论的场景，进入定稿前再核会改变选择的证据。

## 关键词与查询展开

| 拆解面 | 实际词组与适用问题 |
|---|---|
| 对象/身份 | 项目、地址、城市、运营主体、活动、作品、人物、产品型号、租户/机构的正式名、旧名、别名 |
| 时间/场景 | 当前/历史年份、档期、节假日/工作日、开放时段、线上/室内/户外/夜间；不以无关年月限漏原始资料 |
| 人群/需要 | 具体岗位、使用/参与处境、已有认知能力、替代选择、为什么看/来/做/分享、阻力和实际所得 |
| 内容/动作/机制 | 作品、演示、讲解、观看、动手、轮换/复演、投稿/揭晓、预约、服务、付款、兑换、素材生成 |
| 依赖/兑现 | 场地/技术、设备环境、人员能力、容量、排队、档期、价格、权限、库存、接收与售后 |
| 反向/争议 | 与机制相关的失败、投诉、取消、拥堵、误解、尴尬、未兑现、变更、退出和反例 |
| 语言/消歧 | 同义词、行业词、原语言及机制词、译名对应原名、站点限定、城市日期或排除词 |

查询由对象+动作/问题+必要条件组合，根据命中再换别名、站点、语言、反向词或来源。记录实际执行词和变化原因，反复命中转载时换路；无效查询、访问受限和未找到证据分别记录。不以固定平台数、案例数或结果数终止。

## 声明驱动的来源路由

| 待核声明/原料 | 首选路径 | 补充和不能代替的内容 |
|---|---|---|
| 用户目标、范围、授权 | 原Brief、合同及真实决定记录 | 已知缺口集中核，外部文章不能替用户作决定 |
| 策划专业方法及适用边界 | 作者或出版社公开原书正文，记版次、章页、表号或节名 | 目录用于定位。区分作者主张、本项目的协作改法与本次活动的事实或预测 |
| 地方/文化/作品/人物/产品事实 | 原作、档案、作者/机构原文、产品或研发资料 | 专业研究定位原件；宣传形容词不代内容 |
| 日期、地点、阵容、资格和规则 | 当前主办/场地正式资料及变更 | 历史票页/转载不当现行承诺 |
| 场地/技术参数和可用状态 | 场地手册、测量、设备/供应方当前资料、实际核查 | 图片、合同、效果图不能独证当前验收 |
| 价格、档期、合同与成本 | 当前报价/订单/合同及有权确认 | 历史与benchmark仅有条件估算，预算上限不代成交价 |
| 真实体验与口碑 | 授权反馈、参与者原帖/评论、实际使用记录、访谈 | 官方稿、合作内容、转载不当自然反馈或总体比例 |
| 平台能力/账号/数据 | 当前官方文档、实际配置与可用后台 | 平台名不证明支持跳转、互动、退款或去重 |
| 环境与专业适用条件 | 对应官方当前原文、专业方及现场资料 | 记录性质、主体、地点、时间；不照搬海外/旧年要求 |
| 机制与可比效果 | 可比项目真实过程与结果、独立测量 | 主办复盘可支持其自报，不能直接证明本项目有效 |
| 最终工作件对标 | 客户真实模板、往届工作件、主办/制作方同用途材料 | 案例照片、投标演示、概念图和执行手册不是同类样本 |

消费体验可以到小红书、抖音、微博、B站、知乎等原帖/评论；案例灵感可用数英、SocialBeta、广告门或品牌原文，再回原始出处；趋势可用真实可见的热榜与指数；行业数据查发布者、政府统计、协会、财报或报告原文。To B查买方/技术/行业及授权CRM，政企查正式事项/机构原文，内部查组织与员工授权反馈，招聘查真实岗位和候选人反馈，艺术查作品/作者/场地。目录是候选路径，目录外适用源可以采用，不是白名单和必扫清单。

## 访问、读取与原始记录

先核本轮搜索、页面、浏览器、登录、截图、PDF/图像/视频、API和本地读写能力。可用授权内自主读取；站内适合原始声音就先尝试站内，受限后可用site查询、官方/原始公开源、可信原创报道或获授权内部资料。验证码、账号、机构/付费权限只请求必要介入，不编受限数据；不能要求用户替AI做已可完成的公开查询。

分别记录取得状态：公开可读、仅搜索/列表可见、需登录、需付费/机构权、风控受阻、部分取得、不可用、内容不支持声明。随后记录实际阅读范围：全文、指定章节/页/表、评论样本、已看图/帧/时间段、未读范围、截断及限制。取得链接、下载、文字抽取、实际查看、可编辑性核验是不同动作。只看封面/摘要/部分预览，不能称完整案例或成品已核。

采用资料保留source_id、对象/生产者、URL或原文件及定位、发布/发生/访问时间、版本/指纹、同源关系、获取方式/状态、实际读看范围、支持的声明、冲突/限制、影响的决定/模块/产物、时效和重核触发。摘要带这些定位和例外。无发布日期用未知，不补造日期。

官方原文可核其实际公布的日期/规则，不必为单一公布事实硬凑第二来源。总体口碑、效果、策略争议和因果更需要独立及相反证据；同一组织稿、同一次投放和转载不独立。少数评论只能支持这些评论的观察。未发现负面、未看评论、作者推演的失效条件分别表达。

## 图像、PDF、视频与源件

每份采用视觉记录来源、作者/日期可知范围、原页/PDF页/视频时间段、图像类别、实际查看方式、裁取范围、实见观察、借鉴用途和不可推断部分。场地事实图、案例原图、概念效果图、示意/分镜、作品局部、规则/导视和成品截图分别识别。

实际看过相关页才能评价图文层级/空间/画面。文字抽取不代表看过版式，PDF页面不代表验证PPT图层或表格公式。照片能支持可见动作和空间线索，不能证明尺寸、承重、功率、容量、满意度、全天客流、费用或施工可行。生成图不冒充案例原图或现场事实。参考可读、生产授权、高清素材/源件可得、原生可编辑分别核。

用视觉回答“人在哪里做什么、内容如何被看见/听见、选择或成果如何呈现、此图改变哪项内容”。无图时给真实可查原位置和未取得状态；可用文字分镜/示意解释拟案，但不能称约定视觉文件已完成。

## 比较、反证与转内容

横向比较相近条件的实际人群所得、进入成本、内容/动作、周期、资源、服务、素材、接收、成本与结果口径；不可比条件列差异。纵向追对象的实际演变和一次项目的开始—发展—兑现—后续，缺原件不编历史因果。案例只借明确机制/结构/表达，说明保留什么、替换什么、条件差异与失效边界。

重要判断记录支持、最强反证、替代解释、采用理由、成立条件和改法。采用原料沿“原料/来源 → 人群所得 → 具体内容假说/场景 → 与惯常做法的区别 → 依赖 → 验证”进入实际正文；有原料却只有“提升共鸣”仍未完成研究转创作。

## 从资料问题到实际修订

遇到转载，先定位同源而不是增加证据票数；版本矛盾核有效日期和有权主体；过期条件重新取证；原文后部例外须扩读；只看部分就限制声明；发现漏依赖则补查并登记实际采用依据。每项保留“原文位置—当前判断—受影响承诺—正文修改—复验”，不能只在内部报告说存在风险而让客户正文保留旧承诺。

验证接手能力时给具体、可信且不提示答案的任务，让接手者使用实际稿件完成动作。模型走读只能证明对应文本任务的表现；真实岗位和受众能否接手需要实际观察。测试反例是检查工具，不增加所有项目默认模块。

## 充分性与停止

按当前用途核：目标/对象与活动必要性，主方向的真实原料与价值依据，核心内容必要条件，反证及高影响限制，范围/费用/接口，以及剩余缺口的处理。结论为可写案、条件写案、阻断相关定稿。只有影响当前用途的缺口才阻断；独立内容继续。

停止理由是问题已有足够证据作当前判断，或真实获取边界已说明且有处理方式；不是“搜够几篇”。覆盖记录留问题、已得、未得、影响、补查/条件推进、实际读取位置与未覆盖范围。若新增来源或条件变化会推翻结论，重核相关判断；指纹未变不证明动态条件今天仍适用。置信度来自对应声明的证据强度，高/中/低/未知与限制一并表达。
