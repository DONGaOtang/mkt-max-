# 人员、实际文案、设计与制作交接

适用：需要岗位、人力/班次、文案、视觉、页面、空间、影像或生产交付。人员和设计可分别启用；先读共用接口，再读命中节。不预设兼职、拍摄或整套KV。

## 工作先于岗位

从实际动作、同时任务、服务时长、点位/时段覆盖和能力缺口确定谁做什么。先核现有正式人员与真实协作，减少动作、改变节奏、分时服务也可解决缺口；不能每逢活动就招兼职。兼职、员工、志愿者的标签不证明技术、照护或专业资格。

岗位工作件须写成接手者可操作的动作，不能只有“现场协助、维护秩序、负责接待”。每岗定位目的、点位和时间，当前规则/名单/话术/设备版本、负责人和协作、输入物料/权限、动作顺序与完成标准、交出/接收、异常、培训、班次备用、实际费用和出勤结算。

## 产能、班次与备用

先估计各时段真实同时工作和到达分布，参数标实测/历史/报价来源或假设。单点理论吞吐可由有效工位×有效时间÷单轮时间估算；单轮包括解释、操作、指导、检验、设备/材料复位和转交，未知参数先试操作取得。理论上限不证明队列稳定、等待可接受或特殊需求已被覆盖，需缓冲与真实走读。

用实际覆盖时段排班：准备/盘点、岗前说明/试操作、到岗核验、开放服务、峰值增援、交班、休息/用餐、收尾/物资交回。写每班起止、地点、任务、同时可用人数及能力、离岗接收、替班/备用召回方式；培训和收尾也计入工时。跨点位人员计转场，不把一人放在冲突岗位，拍摄不默认兼任指导或照护。没有依据不套人群人数比例。

可变任务发生时，核剩余可用工时、设备、物料和服务量；缺人时由指定负责人选择增援、缩范围、分时、暂停相关服务或改约，不能现场人员擅自承诺加场。备用人手须有真实可用性、能力、响应和费用；只写名单不叫已安排。

## 具体岗位动作

按项目启用并替换成真实对象/版本，以下是工作内容要求，不是本项目人员已落实的声明：

| 岗位任务 | 活动前/开始 | 运行实际动作 | 交班、异常与完成 |
|---|---|---|---|
| 报名接待/核验 | 取得允许读取名单、有效入场规则、容量状态，试核身份/票券和故障路径 | 核当前资格/票状态、记录实际入场，分流无名单/重复/迟到/候补，不公开个人资料 | 名单错配、支付未知或满额转有权岗；交记录及未结问题，不自行改票/退款 |
| 引导/导览 | 走实际入口/路线、可用区域和退出，核当前指示文本 | 提供准确路线、等待/预约信息与服务点，更新已确认变更，不替讲解内容编事实 | 路线失效、拥堵/服务停止交区域负责人；交当前状态和遗留事项 |
| 工作坊辅助 | 核材料/工具、规则、分组和课程，按导师演示试操作 | 按规则发包/辅助核对、解答培训内问题、记录缺料和复位；超能力问题交导师 | 不擅改课程/收费/材料承诺；清点余料、清理约定范围，交导师/物料岗验收 |
| 技术/设备 | 核设备版本、素材、权限、连接与cue，真实测试/复位 | 按指令切换、记录异常，隔离问题设备，采用已确认备用 | 超范围功能/串数据/无法复位停相关动作交技术负责人；交测试和恢复记录 |
| 主持/内容协作 | 取得实际议题、串词/问题、嘉宾任务、时间和公开边界 | 定题、按内容追问、真实收口与提示，不编嘉宾答案/成绩 | 临时换人/内容与时长冲突交内容/总控；未回答问题给实际接收者 |
| 社群/客服/接收 | 核当前页面/规则、权益、话术、工单归属及回应能力 | 接收咨询/申请，记录待判断/有效/无效和下一动作，按授权发送真实可得资料 | 超范围承诺、投诉、退款/售后升级；交处理状态与未履约项 |
| 素材采集/摄影 | 核必需画面、许可范围、不拍区域/选择、时间及服务冲突 | 采真实过程/作品/动作和必要上下文，记录对象/时段/授权，不导演自然好评 | 拍摄影响核心服务或授权不明停相关采集；交真实原片/版本及限制，不称脚本为成片 |

## 培训、权限与费用

岗位说明应交真实任务和当前工作件；培训包括场地/入口、规则/名单/设备版本、动作示范、实际试操作、限权和异常上报、交班及服务口径。核理解不能仅“已读”：按岗位任务完成一次操作/走读，记录培训人、时间、版本、结果与待补能力；规则/设备变化给受影响人员增补说明并确认接收。

可以自己决定什么、什么必须上报写具体边界；真实异常联系人/职能与替补可找到，负责人未定标待指派。涉及名单、账号、订单、健康/儿童等资料，只给完成任务必要权限，不在培训包散发完整客户数据或密码。任务包限制不等于操作系统隔离。

实际人员费用连接人数、班次、工时、单价或包价、币种税口径、培训/准备/收尾、加时、交通餐饮、住宿或其他约定。来源与有效期明确，未知不写0；法定/用工事项按当地当前资料和实际承接方核，模型不编工资、休息比例或责任归属。出勤记录、临时替班、加时确认、验收与结算接收要能对应主账和真实付款状态。

岗位文本已写、人员已安排、培训通过、实际到岗、工作完成和费用结算分别记录，不能互相代替。

## 设计需要从使用问题产生

沿“理解/体验问题 → 使用位置/读者 → 必须的信息与动作 → 实际文案 → 载体与设计 → 深度 → 制作及接收”推导。可以只交说明、规则页面或模板适配；没有需要不重做KV、空间效果图和整套延展。

| 对象 | 本阶段需写出的实际内容 | 设计/制作需核条件 |
|---|---|---|
| 命名/主视觉方向 | 主张、活动标题/必要副题、核心画面含义、适用语境和禁区 | 品牌依据、参考解释、方向与成稿状态 |
| 海报/活动页/邀请 | 对谁有何具体价值、真实内容、日期地点/线上入口、资格费用、参与动作、当前限制/变化和联系 | 使用位置/媒介、阅读层级、链接/二维码可用、公开权限 |
| 导视/规则牌 | 此处做什么、如何开始/完成、准确方向、提示/限制、满额/异常交谁 | 观察距离、实际点位、遮挡、材质/尺寸/数量与安装 |
| 展项/节目/导览 | 展示对象、来源与解释、观看/操作提示、必要前情/结束、状态 | 载体长度、现场光声、无障碍/语言及原件权利 |
| 屏幕/播控/直播页 | 实际字幕/口播/提示、真实议题与素材、切换/失败信息 | 设备比例/格式/测试、cue、可用素材和回放权限 |
| 印刷/包装/票券 | 实际正文、规格/使用条件、权益/规则版本、编号与客服 | 数量、可核印制参数、批次、源文件/印刷件、版本替换 |
| 短视频/影像 | 镜头/人物/动作、实际旁白字幕、需保留的条件、开端推进收束与CTA | 原片/脚本/粗剪/成片区分，取得、编辑、授权、审稿和输出规格 |
| 空间/体验方案 | 谁在哪里看听做什么、路径/站位/转场与内容关系 | 概念示意与实测图分开；尺度、结构、用电/容量由真实资料确认 |

实际文案由本次负责内容的作者写出；“设计方补文案”不算完成。清楚说每条正文解决什么问题，用本项目真实名词/动作/信息，不用“高级、沉浸、互动”作成稿。仍缺时间、资格或价格的稿件标条件拟稿，不宣称直接印制/发布。

## 概念、图稿、源件与生产

方向评审、设计方案、内容/版式稿、原生源件、制作交付、实际安装/使用是不同完成层。文字Brief/提示词是输入，分镜是视觉简报，实际图片是图稿，截图不代表可编辑源件，主视觉不能冒充施工图，导出文件也不能补齐未创作内容。

制作契约写对象/版本、使用位置、规格来源或待核、尺寸/比例/材质、数量、出血/格式等实际需求、可编辑源件/字体素材、安装、打样/测试、截止、内容/设计/制作提供者、反馈窗口、验收和变更。未知参数留待场地/供应方，不从效果图猜承重、功率、通道或参数。概念阶段可给建议比例和待核，不提前承诺施工。

核文件真实可打开、文字/规则准确、约定编辑对象可用、附件/素材已取得且授权范围匹配、规格经实际责任方确认；生产件核数量/版本、安装/播控或现场接收。不把“Brief已交”改写为“设计完成”，也不以视觉漂亮抵销内容缺失。

## 修改传播及共用接口

规则、价格、权益、场次、地点和资源变化时，检查海报、页面、导视、展项、屏幕、视频字幕/口播、源件及已生产/已发布版本；各处须核当前事实和状态。旧件失效、替换/返工/取消及费用进唯一主账；只改源稿不称页面/现场已更新。设计交接连到实际制作和发布接收，不以“统一风格”结束。

餐饮、运输、搭撤、物流、嘉宾、照护、语言、摄影、客服、售后等新增实际服务也用“谁交什么给谁—何时—规则/规格—验收—异常”接口，按[执行与复杂度](execution-and-complexity.md)展开需要的操作，不用“其他由执行方负责”兜底。
