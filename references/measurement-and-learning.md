# 指标、预测、收尾与条件性学习

适用：确定成功判据、估算、实验/预检、真实数据回填、运营决定、收尾和经验迁移。第一阶段从真实目标定判据，不默认财务ROI、成交、社媒量或四层全图；局部任务只检查相关目标与口径。

## 目标与作用路径

价值先于指标：本次要让谁理解、欣赏、学会、交流、得到服务或作判断/行动，哪种实际观察能说明取得或改变取舍。数量、质量、效率、成本和长期价值用于补漏，不强每项建指标。不能用到场/曝光替内容质量，完成场次替受众结果。

需要解释作用时记录适用投入→过程→受众所得/结果→后续资产及待验证关系，已有有效模型直接引用。箭头是机制假设，不证明因果；满意度、到场和成交同时提高也可能受其他因素影响。没有量化条件可定义具体可观察信号和核验者，不能把未知结果填目标百分比。

将建议的成功判据、实际可采信号和采集代价交目标负责人判断，记录本轮采用范围。助手完成定义、取数核查和计算，观察结果仍按证据解释。更换主判据可能改变活动方向时，回到对应人工节点。

## 完整关键指标字典

关键指标由同一主定义维护，其他正文/工作件引用metric_id。不以多张KPI表重复定义。

| 字段 | 必须确定什么 |
|---|---|
| metric_id、名称和用途 | 支持哪个目标/决定，关联全期、单元、场次、资产或实际服务对象 |
| 对象、事件和单位 | 谁/什么在何种条件下被计数，排除范围，次数/人数/人次/金额/时长或定性记录 |
| 分子 | 事件资格、有效条件、状态和计算，不把所有提交默认有效 |
| 分母 | 同一对象/队列/可识别范围和观察窗口，含/不含什么；无适用分母明示，零/缺失分母不能虚算比率 |
| 时间、时区和截点 | 事件与取得时间、起止/边界、数据截至、延迟和后续窗口，比较时一致 |
| 基线 | 真实来源、时间、条件、覆盖/可比性及差异，缺失标未知 |
| 目标、估算/预测、实绩 | 每种类型、版本与来源分开，预测更新不覆盖原目标/预测 |
| 去重和匹配 | 对象ID/订单/事件键与规则、跨场/渠道匹配能力、覆盖和漏识别；未匹配不声称独立人数 |
| 数据来源 | 实际原始记录/后台/工具/文件定位，定义与采集/清洗步骤，原始/清洗后值分别保留 |
| 采集与接收 | 负责职能、工具/成本、采集时点、交给谁、复核及维护 |
| 访问及使用权限 | 是否真能取、哪些字段/对象/用途可用、权限或接口限制 |
| 缺失与异常 | 缺失时段/对象、迟到/重复/错配/故障、排除依据、修订记录及能否补取 |
| 决策条件 | 哪种观察促继续/调整/暂停/恢复，阈值或定性条件及预先依据 |
| 证据/置信度 | 取得状态、来源/版本、方法与限制，高/中/低/未知及不能证明什么 |

不存在数据不是零，目标不是预测，容量不是预计人数，主办自报不是独立效果证据。未发生窗口保持未取得/不适用，不把取消后的未发生时段填零实绩。

## 容易混淆的口径

| 观察项 | 精确定义边界 |
|---|---|
| 曝光/播放/可见触达 | 按各平台真实定义和截至记录；曝光次数不当独立人群，跨平台相加不当去重触达 |
| 理解/记忆 | 依据实际材料、接触顺序与未提示回答；内部模拟、小样反馈与总体测量分别报告 |
| 报名/确认/连接/实到 | 状态和事件不同；相同口径匹配才算到场率，门口计数不自动有报名分母 |
| 同时在场/容量 | 特定时刻在场计数和已确认上限，不是全日/全期累计，也非需求预测 |
| 累计参与/到访人次 | 按重复进出、跨单元和跨场规则计次数；抽样估计与签到实数分开 |
| 可识别去重人数 | 在明示范围用稳定可匹配标识去重，报告覆盖/漏识别，未识别者不默认新客 |
| 复访 | 约定窗口内已识别者的后续到访，人数/次数分列，分母限同样可识别到访者 |
| 有效线索/商机 | 根据真实业务资格和判断状态，提交、有效、跟进、业务结果分开 |
| 意向/合同/到账/履约 | 不同证据事件，签约舞台、名单和意向金额不代收款与服务 |
| 订单/GMV/退款/净收入 | 说明计价、支付/履约、取消/退货、税/费/补贴、窗口及结算口径，不直接当利润 |
| 归因结果 | 按入口/代码/多触点与窗口关联，重复事件只计一次；关联不证明活动增量 |
| 增量与财务回报 | 需适用反事实/基线/比较及收益成本口径，无法支持时只报实绩/变化/关联信号 |
| 学习/服务/文化所得 | 内容产出、任务完成、理解/技能、后续应用或受益效果分开，短期完成不代长期变化 |

开放空间全场计数可能含路过、普通消费和工作人员，活动点位人次与实际参与分别采集；照片人数不外推全天。合作名单、自然表达、官方稿和付费内容分别计数，合作曝光不写自然传播。

## 预测与有条件情景

有比较价值且有依据才建立预测：目标、可比基线、参数/单位/分母/来源/时效、计算、敏感条件、当前容量/资源上限、置信度、缺口和实绩验证方法。可用有效报名×有据到场参数等关系，但必须说明条件与误差，不能曝光乘臆定转化率得实到。

情景数量由关键不确定性与取舍决定，不固定保守/基准/积极三档。缺参数只交条件关系与采数要求，不编数字以显完整。预算、场次、人员、入口和规则变化后复验相关参数；跨场人次不能加成独立人数/全体复访率，容量不充预测分母。

## 验证与数据质量

关键受众/内容/运行假设需要可用证据或明确条件处理。选当前最能改变决定、实际可获的验证，不给所有正式方案强制AB。桌面走读、真实反馈、读剧/试演、技术彩排、访谈、原型测试和正式实验分别记录，计划不称已做。

验证定义假设、可改变决定的观察、实际材料/版本、输入/对象/渠道/范围、主要变量、采集、判据/护栏、失败改法及权限。严格AB在结果前定样本/周期/分配和停止规则，不中途看数据就宣布胜出；多因素同时变动解释范围受限。小样只报方向性反馈/观察，不推出总体比例或确定因果。

取得数据先查身份/项目匹配、时间与覆盖、重复/漏记、平台定义、来源状态、采集/清洗、拒访/响应差异、异常与权限。备份只能支持自己的证据：访谈能解释体验不代问卷总体比例，截图支持可见值不造后台去重，抽样/摄影留范围不外推全场。无法补取就记录缺失及决定限制，不用行业比例补未知。

## 继续、调整、暂停与恢复

在现有工作件记录对象/版本、目标贡献、事实/缺口、观察窗口、竞争解释、当前兑现容量、后续可变投入/已签义务的cost_id、决定/理由、授权责任、复核时间和恢复条件。阈值由项目基线/成本/目标/容量定，不设统一点击率、播放、ROI或满额百分比。

继续须入口/内容/服务可用且投入有据在授权内；调整须指明实际改稿/素材/规则/受众/入口/服务对象、负责人和验证；暂停明确停哪些新增发布/招募/支出，必要服务更正继续；恢复有实际修复/复验、接收和有权决定，不因日期到来自动恢复。暂停发布不等取消合同、清零成本或放弃已经承诺的服务。

传播高而兴趣弱，核人群、承诺、内容和可测入口；报名高而到访弱，核时段/出行/费用、提醒、容量状态、兑现理解和漏记；到访高而参与/核销弱，核实际体验/等待/库存与服务；复访弱核新价值、通知、识别覆盖。上述是竞争解释，不是直接结论。反馈产生“原始观察→偏差→最强替代解释→补证→具体修订→版本/责任/期限→下一观察”，不能只多写建议表。

## 收尾与全链路兑现

在方案交接时就约定适用收尾责任：资料/回放/问题补答，销售/客户跟进，客服/退款/失物，库存/设备/借展交回，供应验收/损坏争议/财务结算，合作权益证明，原片/源件/授权整理，数据核对、撤权及留存。仅涉及文本就不自动承担整场收尾，但不能丢本次承诺。

每项写交出/接收、期限/条件、验收、异常与当前实际状态。活动发生后才回填实绩；未取得数据交清楚标识的结构与缺口，不填成功结论。复盘/周度/场次/异常时点由实际调整窗口和采数能力定；长期指标按约定观察，不自动创建定时监控或外发报告。

## 经验与方法沉淀

可复用结论必须保留“条件 → 动作/内容版本 → 实际观察 → 替代解释/反证 → 可迁移部分 → 不适用边界 → 重核触发”，加人群/参与阶段、时间环境、资源/成本、履约/测量条件、来源和样本/缺失范围、置信度及下一最小核查。

项目经验先留项目目录；未经实际验证和明确采纳不升级通用reference。单次失败支持当前条件下调整，不能变永久禁用；单次成功也不保证跨行业、地域、周期或人群。方法改善提议与客户事实分开，不跨项目散发客户资料。

系列复盘还核局部热度是否挤占后期内容制作、接待/商户服务或全期预算，素材/关系是否仍可使用；未知影响不填收益。让未参加原项目的接收者能据记录说清何时可用、不能证明什么、哪些资源/报价必须重核，才进入可复用索引。新增参考文件数、模型评分和表格齐全不算学习完成。
