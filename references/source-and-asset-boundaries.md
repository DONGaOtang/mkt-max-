# 资料、素材、权限与公开边界

适用：读取客户/内部原件、分发任务包、参考素材转生产、影像/UGC、原生编辑文件、发布或后续归档。按访问、使用与交付分别判断，公开可读不表示可生产使用。

## 来源和文件保留

原件保留，采用版本有source_id、文件/URL定位、发布/发生/访问时间、原件指纹、实际读取范围、限制/同源、支持声明与影响对象。导入旧项目保留原件和导入版本，不默认覆盖旧目录；旧计划、实绩、预算/报价、台本、影像和源件按真实性质接入，历史状态不继承成本期确认。

全文、提取文本、摘要、转载、截图/视觉观察与策划推断分别辨识。摘要带原件、版本、范围、例外、未决；引用到具体原段/页/帧，不仅堆一串URL。关键源变更或动态条件失效时标相关摘要/判断待复核。搜索/下载/抽取/读看/编辑性核验不同，完整索引与实际读看覆盖不同。

## 任务必要访问与现实权利

主控维护完整目录，接手人读有权限且完成任务必要的原文。真实合同、个人信息、名单、健康资料、儿童/家庭关系、未发布产品、内部运营/财务数据不默认给所有Agent、供应方、合作方或客户。

按资料记录提供者、实际持有/控制方、允许对象、用途、必要字段/范围、渠道、期间、是否可转交/公开、负责核验与当前状态。用户上传供分析不自动授权外发、营销、出售或跨项目使用。作者身份和AI角色名称不创设权限，参考许可与制作使用权分开。

可用范围不足时先采用有权可读的公开/脱敏/最小资料，明确会限制的判断和真实缺口；必要源无法取得，提交具体对象/用途/截止/处理的资料请求草稿，不无授权实际发送。不同职能可拿不同必要摘录/操作状态，同一事实主定义仍保持一致。

首版任务包的说明和过滤只是信息安排，不称操作系统/文件权限隔离；继承聊天历史的Agent可能已经得到此前内容，不能声称缩包就撤回访问。跨机器同步、后台接口和权限配置未实测不称可用。

## 素材从参考到生产

| 对象 | 必须核实/记录的范围 |
|---|---|
| 作品、文字、音乐和图像 | 来源/作者、可参考与可制作区别、复制/改编/演出/发行或使用范围、对象/渠道/期间、权利负责人 |
| 肖像/采访/嘉宾 | 真实身份/内容、拍摄与使用选择、现场/直播/回放/剪辑等用途、公开口径与撤回/变更接收 |
| UGC/投稿/参与成果 | 参与与宣传/二次使用分开、署名/改编/展示条件、判定与未入选、素材真实性、接收和实际许可 |
| 场地/案例图 | 原位置与实际观察范围、事实图/效果图/示意区别、生产授权和高质量原件可得性 |
| 未发布产品/客户案例 | 可讲的事实/版本、保密与脱敏、公开/对比/演示边界、真实审批/权利证据 |
| 数据/名单/订单 | 必要用途/字段/接收/保留、可用匹配/去重、外部分享依据，不默认包含于赞助权益 |
| 字体/模板/软件及素材包 | 实际许可/可交对象、源件依赖、嵌入/编辑/生产范围、第三方交付条件 |

未核权利保持参考/待核，不宣称客户可用资产；图片URL不表示高清原件、下载、已交摘图册或可编辑源件。AI生成/拟制的效果图、分镜与文稿标创作性质，不冒充案例原图、测绘图、真实反应或已生产件。

## 拍摄、拒绝与变更

按实际任务设计素材采集，不把参加、付款、签到或接受服务等同宣传选择。需要不拍摄标识/区域/绕行时落实到接待、摄影、空间和发布接收；拒拍/拒社交仍按本次核心承诺提供服务。儿童、照护、健康、婚恋等对象的具体操作按[执行与复杂度](execution-and-complexity.md)命中节。

发布前核素材对象、事实/版本、用途/渠道/期间和许可状态；临时更换嘉宾、节目、机位、价格/规则、片段或渠道重新核受影响内容。授权撤回和投诉明确受理、停止尚未发生使用、更正/下线/保留删除责任与实际结果；不能假称已撤销他人已经获得的资料。

## 客户件、内部件与原生交付

客户正文按其用途给完整内容、关键依据短注与影响判断的条件，内部完整研究、中枢、决定/历史、合同/名单不默认作为客户附件。不能为了“干净”删核心未核条件，也不能把审计标签散布到每条普通文案妨碍使用。

交付表定位实际正文/稿件、文件、源件、附件、版本、读者和验收；源稿与导出一致。可阅读PDF、可编辑Word/PPT/表格、图片、原生设计/影像源件、字体/链接素材及印刷/播控件各有完成要求，截图/文字Brief不代源件，改后缀不代格式，文件存在不证明约定编辑对象完整。

宿主只能生成Markdown或脚本组装时，保存真实源稿和准确未交项；按实际可用工具完成其他约定格式，不能宣称不存在的原生能力已生效。打包只含技能必要资源和来源说明，不混客户资料、测试运行数据、临时文件、密码/账户凭据。

## 外部执行与回执

发布、投放、邀约、外联、采购、预订、付款、退款及外部系统写入按任务既有授权和真实工具能力执行；草稿和计划不当已发送/已发布/已购。普通文本编辑不凭假想风险添加统一审核，实际审核由用途、权利/合同、专业要求与现有授权触发。

执行记录留对象/版本、操作时间、实际操作者/授权、渠道/目标、回执、失败/部分及下一处理。真实外部事件在文件回滚后仍保留，回滚不能撤销消息、合同、订单或付款。

## 留存、移交与再用

在本次资料/素材的实际用途下确定保存、移交、撤权/清理、撤回请求和期限责任；不为“知识沉淀”无差别永久保留敏感原件。已发生记录、合同/财务/服务证据按当前约定和适用要求保留；删除/清理若未实际完成不能写完成。

项目经验进入项目目录并带条件与来源，客户事实不自动进入通用reference或其他项目。再用时重核权利、事实、资源/报价时效和目标差异；参考可达及权限过滤均以实际验证为据。
