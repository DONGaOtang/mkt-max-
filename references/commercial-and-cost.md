# 商业范围、唯一成本、价格与履约

适用：费用、预算/报价、收入、采购、乙方委托、竞标、合作、赞助、票券权益及变更。先按价格用途选节，不把不同目的账本加成伪总额。不默认三档预算、固定应急比例、招募赞助或比稿话术。

## 不同价格与资金用途

活动实际成本、乙方服务/转售报价、合作权益价格、媒体费用或效益分析分别说明目的和付款主体。需要活动成本时引用同一费用主账；报价可能包含已在主账的第三方成本和服务费，不能再次相加。资源置换估值不同于现金收入，目标收入、意向、签约、应收、到账、退款和结算分别记录。

预算上限是约束；估算/情景来自显式参数；报价是供应方当前条件；下单、已付款、实际结算各有回执。未知金额用null或待询价，0仅用于确知无该费用/真实免费，不将未报误作免费。用户接受某估算仍不证明供应方可成交。

## 唯一费用项

| 字段 | 实际要求 |
|---|---|
| cost_id与对象 | 一次登记，关联单元/场次/资产/资源、用途及覆盖期间 |
| 数量与单位 | 人/件/小时/班/场/天等实际口径及来源，次数/时长可复算 |
| 单价/参数及金额 | 计算关系、区间/假设与依据，不编市场价 |
| 币种和税费 | 含税/未税、税/服务费、汇率来源/日期及转换口径 |
| 包含范围 | 设计/制作、运输/装拆/差旅、修改、技术、采购等真实包含和未包含 |
| 来源/有效期 | 当前报价/合同/订单、历史/benchmark或假设，适用版本和期限 |
| 共享/增量 | 共用一次成本、单场/改期增量、分摊分析的关系 |
| 状态与责任 | 估算/报价/下单/付款/结算、支付方/审批/验收、实际凭证 |
| 变更 | 新旧值、原因、可退/追加/损耗/重做、对象及当前确认 |

固定、可变和阶梯成本按实际合同/服务量分类；不能仅按行业名称归类。准备、培训、休息替班、收尾、清洁/复位、采集/制作/审核、转场、仓储、返工和后续服务等实际任务要进入费用或有真实已确认资源。免费/赞助/借用也有来源、权利、容量/期间与状态。

同一共享装置、场地、人员包价、月度合作或投放合同只计一次，其他位置用cost_id引用；分摊是分析视图，不增加总额。费用求和核币种、税口径、可选项与重复包含，数量/人数/场数/资源版本一致。不同币种无有据转换不直接合计；实际已包含应急/税/管理费不再重复加。已知必需费用不能藏入应急金。

## 分摊变更与逐项修复

只计当前有效分摊的已知金额小计；存在未知项仍不能使已知小计超出母费用。更新同项先排除旧值，失效分摊保留为待核记录、不重复增加总账。母费用金额、币种、税口径、类型或依据变更，先记录真实新条件并沿关联对象标待核，再逐项重写分摊和相关正文；不能为迁就旧分摊拒绝真实母费用变更。母费用自身失效时不能据其建立新的有效分摊。费用审计的核验状态、问题和未知金额均须看，不能只读合计。历史快照完整性与当前费用是否仍适用分别核。

## 投入价值、情景与现金

解释钱怎样支持内容、进入/服务、实际发生、约定资产和必要保障，用本案目标说明保留或删减的代价；预算占比不证明价值。主目标可为文化、学习、关系、服务，不为ROI伪造货币收益。

比较不同规模/配置仅当有助于决定或用户要求；各方案说明实际内容、条件、成本、损失和不可替代项。档数/名称与应急储备由真实敏感条件决定，不能统一Lean/Base/Stretch或10%。若缩预算删除已明确内容/场数/权益，要显式显示范围差异和需决定的承诺。

需要现金安排时列付款节点、押金/预付、验收后付款、返还/取消、资金峰值和支付责任，引用真实合同条件，不编比例/账期。应收赞助/票款未到账不能当当前可用预算。已完成服务和已发生第三方成本如何处理以实际订单/合同和可退范围为据。

## 委托、采购与乙方报价

先读正式Brief/合同/招标/采购模板和评分标准，区分客户硬要求、当前适用要求/提交规范、历史范例、平台样本和本次建议；后几类不自动升级硬规定。作者负责实质创作，客户提供的是具体事实、资源和授权，不把未写故事/规则推给客户。

服务契约应落实实际模块、我方/客户/第三方责任、深度、读者、交付载体/原生编辑对象、数量、节点、包含/不含/可选、客户资料/资源及截止、事实/技术/内容审核责任、反馈窗口、修改机制、验收/付款、变更/取消与遗留接收。无相应服务就不列默认大全。报价核服务费、第三方、媒体/达人、税费和可选项，不把整场外部成本误称已包含。

竞标时用真实问题、完整活动内容和实现条件解释差异、投入价值、范围及风险；可以给对当前评分/决策有效的短决策表达，但不编竞品打法、往届客户、案例、获奖、资源或报价。缺竞争信息标未知，正式招标条件优先，不默认拉踩或构造中标保证。

## 验收、付款与变更

验收以真实内容、格式、版本、数量和接手用途判断；最终稿、商务/技术确认、资源已到、实际工作和真实效果分开。约定Word/PPT/表格/源件须真的可读可编辑；概念文本可审阅不等施工完成。付款依约定节点/证据和有权接口，不由文件状态自动支付。

变更记录提出者、对象/新旧范围、原因/证据、时间/质量/资源/费用/风险影响、已发生与可变成本、需要决定和当前授权、改稿/排期/通知/费用责任、验收/复核。截止和加费规则据本案约定，不编“活动前几天一律不改”。反馈延迟要核双方约定和实际影响，不自动归责。

取消/延期核实际已完成服务、已发生第三方和可退范围、库存/退款、供应档期、资源复用、资料/素材、通知和后续交接。暂停宣传不等取消合同，回滚文件不撤销交易。重做、转场、额外服务和取消费进入主账，旧报价不能无核沿用。

## 合作、赞助权益与库存

只有合作/赞助任务或资源依赖启用。先解释活动本身、真实受众为何参与、合作方如何有价值地出现、其投入对应什么可取得权益与证明；权益名目数量不能替代内容与承接。

每权益有ID、持有/授权方、真实对象/位置/时段/次数/规格、库存/容量、排他和竞品限制、价格/资源值依据、提供/审核/接收、交付节点、证明及未兑现处理。冠名、舞台/专场、展位、作品/采访、商户、席位等候选都须真实可分配，不编名额、领导会见和阵容。独占库存不重复卖，档位只按当前资源和对象需求设计，不套固定数量。

数据权益核实际处理依据、允许对象/字段/用途/期间与接收；不能承诺完整未经许可名单。现场、直播、回放、采访/剪辑、Logo等使用权分别核。拟邀、意向、已联系/报价、合同、到账、执行与履约分别有依据；名单和舞台展示不能提前写实际结果。

履约将权益逐项连到真实稿件/物料/点位/服务，记录素材交付、审核、安装/发布/展示、责任、截止、状态与实际证据；合同在场不代表每项已交。素材延迟或资源变化显示受影响权益和替代/补交/改价条件，不能声称等价而无依据。

合作报告按约定对象列承诺与实际、照片/链接/可见数据、服务/参与、获准线索及接收、内容资产和遗留；未发生只交报告结构，不填成功数据。仅有成本与可归属货币收益才计算对应财务指标，曝光/线索/履约分别报告，不能虚构广告等值或保证销量。续约依据条件与观察，重核本期库存和价格。

## 商业检查

从一个实际内容或权益追到资源状态、合同/报价、唯一费用、付款/验收和履约证据，再看范围变化是否同步正文/公开信息。未知金额、未授权资源、重复成本、排他冲突和未完成接收要改实际账/承诺，不能靠“风险可控”通过。测量见[测量与学习](measurement-and-learning.md)，动态票务库存见[执行与复杂度](execution-and-complexity.md)。
